# Narfi v2.0 仕様（核の論理）

この文書は **kernel が何を検査するか** を定める。表層の構文（`Fix`・`Obtain`・連鎖など）は
elab が kernel の証明項に翻訳する（§8）。kernel の外のコードは、この仕様の正しさに関与しない。

---

## 1. ソート

```
σ ::= ℕ | ℤ | ℚ | ℝ        数のソート
    | 'a | 'b | …           ソート変数（定理の図式の中だけに現れる。§7）
```

関数記号・述語記号の型は次の形をとる（関数型の値は v2.0 にはない。§9）。

```
関数記号 f : σ₁ × … × σₙ → σ      述語記号 P : σ₁ × … × σₙ
```

## 2. シグネチャ

### 2.1 組み込みの記号

| 記号 | 型 | 使えるソート |
|---|---|---|
| 数字 `0, 1, 2, …` | σ | ℕ ℤ ℚ ℝ（文脈から決まる。§3.2） |
| `S` | ℕ → ℕ | ℕ |
| `+`, `·` | σ × σ → σ | ℕ ℤ ℚ ℝ |
| `-`, `neg`（単項の −）, `abs` | σ × σ → σ / σ → σ | ℤ ℚ ℝ |
| `/` | σ × σ → σ | ℚ ℝ |
| `max`, `min` | σ × σ → σ | ℕ ℤ ℚ ℝ |
| `^` | σ × ℕ → σ | ℕ ℤ ℚ ℝ |
| `=` | σ × σ | すべてのソート |
| `<`, `≤`, `>`, `≥` | σ × σ | ℕ ℤ ℚ ℝ |

`a ≠ b` は `¬(a = b)` の略記、`¬φ` は `φ → ⊥` の略記。

### 2.2 局所的な記号

定理の文に現れる、組み込みでも定義でもない記号は、その定理の **局所記号** である
（`P(x)`、`a(n)` の `P`・`a` など）。型は宣言（`a : ℕ → ℝ`）か推論（§3.3）で決まる。
定理は局所記号について **図式**（どんな解釈でも成り立つ）として扱われる。

## 3. 項・論理式と型付け

```
t ::= x | n（数字） | f(t₁, …, tₙ)
φ ::= P(t₁, …, tₙ) | t₁ R t₂ | ⊥ | φ → ψ | φ ∧ ψ | φ ∨ ψ | ∀x:σ. φ | ∃x:σ. φ
```

### 3.1 型付け規則（kernel が検査する）

- 変数 `x` の型は文脈で宣言された σ。
- `f(t₁,…,tₙ)` は、各 `tᵢ` が `f` の引数の型を持つときに結果の型を持つ。
- `t₁ R t₂` は両辺が同じソートで、`R` がそのソートで使えるときに論理式。
- 束縛変数の型は必ず書かれている（elab が推論して埋める。kernel は推論しない）。

### 3.2 数字の型

数字だけからなる項（`2 + 2`、`1/2` など）は、周りから型が決まらないことがある。
このときは、使われている演算が意味を持つ **最小の** 数のソートで読む
（`+ ·` だけなら ℕ、`-` があれば ℤ、`/` があれば ℚ）。
ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ の埋め込みは `+ · - / < =` を保つので、どのソートで読んでも真偽は変わらない。

### 3.3 型の推論（elab の仕事。kernel は信じない）

elab は単一化で型を決める。決まらないときの扱い：

- 数字だけの部分 → §3.2 の規則。
- 変数で、数の演算に使われているのに ℕ/ℤ/ℚ/ℝ のどれか決まらない → **エラー**（`x : ℝ` と書かせる）。
- 何の制約もない変数（`∀x. x = x` の x など） → 定理ならソート変数 `'a` にする（§7）。

## 4. 判断と文脈

```
Γ ::= · | Γ, x : σ | Γ, x : σ := t | Γ, h : φ
Γ ⊢ p : φ      「文脈 Γ で、証明項 p は φ を示す」
```

`x : σ := t` は局所的な定義（`let`）。仮定の名前 `h` は重ねてよい（後のものが見える）が、
変数の名前は重ねてはならない。

## 5. 推論規則（kernel の証明項）

`φ ≡ ψ` は §6 の定義的等しさ。規則の前提で「φ が ∀ の形」などと言うときは、
先頭の定義を展開してから形を見る（§6 の whnf）。

| 証明項 | 前提 | 結論 | 条件 |
|---|---|---|---|
| `Hyp(h)` | `h : φ ∈ Γ` | φ | |
| `ImpI(h, φ, p)` | `Γ, h:φ ⊢ p : ψ` | φ → ψ | |
| `ImpE(p, q)` | `p : φ → ψ`, `q : φ'` | ψ | φ ≡ φ' |
| `AndI(p, q)` | `p : φ`, `q : ψ` | φ ∧ ψ | |
| `AndE(左/右, p)` | `p : φ ∧ ψ` | φ / ψ | |
| `OrI(左/右, ψ, p)` | `p : φ` | φ ∨ ψ / ψ ∨ φ | |
| `OrE(p, h₁.q₁, h₂.q₂)` | `p : φ ∨ ψ`, `Γ,h₁:φ ⊢ q₁ : χ`, `Γ,h₂:ψ ⊢ q₂ : χ'` | χ | χ ≡ χ' |
| `AllI(x, σ, p)` | `Γ, x:σ ⊢ p : φ` | ∀x:σ. φ | x は Γ に現れない（固有変数条件） |
| `AllE(p, t)` | `p : ∀x:σ. φ`, `t : σ` | φ[x := t] | |
| `ExI(∃x:σ.φ, t, p)` | `t : σ`, `p : φ'` | ∃x:σ. φ | φ' ≡ φ[x := t] |
| `ExE(p, x, h, q)` | `p : ∃y:σ. φ`, `Γ, x:σ, h:φ[y:=x] ⊢ q : χ` | χ | x は Γ・χ に現れない |
| `BotE(φ, p)` | `p : ⊥` | φ | |
| `Raa(h, φ, p)` | `Γ, h:¬φ ⊢ p : ⊥` | φ | 古典論理 |
| `Cut(h, φ, p, q)` | `p : φ'`, `Γ, h:φ ⊢ q : χ` | χ | φ ≡ φ'（`have`） |
| `Let(x, σ, t, q)` | `t : σ`, `Γ, x:σ:=t ⊢ q : χ` | χ[x := t] | |
| `Refl(t)` | `t : σ` | t = t | |
| `Subst(p, z, φ, q)` | `p : s = t`, `q : φ'` | φ[z := t] | φ' ≡ φ[z := s] |
| `Ind(x, φ, p₀, k, ih, p₁)` | `p₀ : φ'₀`, `Γ, k:ℕ, ih:φ[x:=k] ⊢ p₁ : φ'₁` | ∀x:ℕ. φ | φ'₀ ≡ φ[x:=0], φ'₁ ≡ φ[x:=S(k)] |
| `Trans(p, q)` | `p : a R b`, `q : b' R' c` | a R'' c | b ≡ b'、R・R' の向きが合う（§5.1） |
| `Antisymm(p, q)` | `p : a ≤ b`, `q : b ≤ a` | a = b | 数のソート |
| `NatNonneg(t)` | `t : ℕ` | t ≥ 0 | |
| `Ring(l, r)` | | l = r | §7.1 |
| `LinArith(φ, ps, cs, c)` | `pᵢ : 不等式` | φ | §7.2 |
| `Decide(φ)` | | φ | §7.3 |
| `Thm(名前, σs, ts)` | | 定理の図式の具体化 | §8 |
| `Sorry(φ)` | | φ | **未完成**として記録される |
| `Line(n, p)` | `p : φ` | φ | 論理的な意味はない（エラーの行番号を示す印） |

### 5.1 推移律の向き

`=` はどちらとも組める。`<`・`≤` 同士は `<` か `≤`（どちらかが `<` なら `<`）。
`>`・`≥` 同士も同様。`<` と `>` のように向きが逆のものは組めない。

## 6. 定義的等しさ

kernel は次の3つの書き換えで同じになる論理式を同じとみなす。

- **α**：束縛変数の名前の違い（`∀x. P(x)` ≡ `∀y. P(y)`）
- **δ**：`def` の展開（`is_lim(a, α)` ≡ その本体）。定義は再帰しないので展開は必ず止まる。
- **ζ**：`let` の展開（`x := t` のもとで `x` ≡ `t`）

**whnf**（弱頭部正規形）：先頭が定義された述語である限り展開したもの。

## 7. 算術

数のソートは次の構造を持つと **仮定する**（これが算術の公理系である）：
ℕ は可換順序半環、ℤ は可換順序環、ℚ・ℝ は順序体。ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ は埋め込みで、
`S(n) = n + 1`、数字 `n` は `S(…S(0))` と同じ値。

kernel はこの公理から直接出る事実だけを、計算で確かめる。

### 7.1 `Ring(l, r)`：環の等式

`l - r` を多項式に正規化し、0 になれば `l = r`。正規化では：

- `S(x)` は `x + 1`、`^` は指数が数字のときだけ展開、`x / c`（c は 0 でない数字）は `x · (1/c)`。
- それ以外（`abs(t)`・`max(s,t)`・`x/y`・局所記号 `a(n)` など）は **原子**（ひとつの変数）として扱う。
  原子の引数は正規化してから比べる（`abs((a+b)-c)` と `abs(a-c+b)` は同じ原子）。

これは「関数は等しい引数に等しい値を返す」（合同性）と環の公理だけを使う。
`x/0` の値は決めていないが、原子として扱うので値を決める必要がない。

### 7.2 `LinArith(φ, ps, cs, c)`：線形算術の証明書（Farkas の補題）

各 `pᵢ` の結論を `eᵢ ⋈ᵢ 0`（⋈ ∈ {>, ≥, =}）に直す（`a < b` は `b - a > 0` など）。
目標 φ の否定も同じ形 `e ⋈ 0` に直す。証明書は係数 `cᵢ`（と否定に掛ける `c`）。

kernel は `Σ cᵢ·eᵢ + c·e` を §7.1 で正規化し、定数 `k` になることを確かめる。
`⋈` が `>`・`≥` の項の係数は 0 以上でなければならない（`=` は符号自由）。そのうえで
**k < 0、または k = 0 で係数が正の `>` がある** なら矛盾なので、φ が成り立つ。
すべての項は同じ数のソート（ℕ のときは ℤ に埋め込んで計算する）でなければならない。

### 7.2.1 桁あふれ

有理数は 128 ビット整数の分数で計算する。桁あふれを検出したら検査を止める（誤って通さない）。

### 7.3 `Decide(φ)`

変数・局所記号を含まない φ を有理数で計算して真なら φ。`abs`・`max`・`min` は通常の意味で計算する。
0 での割り算を含むときは計算しない（拒否）。

## 8. 理論：公理・定理・定義

- **公理**（`axiom`）は図式として環境に入る。kernel は、どの定理がどの公理に依存したかを記録する。
  prelude の公理（等号・ペアノ）は **核の公理**、それ以外は **利用者の公理** として区別して報告する。
- **定理** は kernel が証明を検算したあと図式として環境に入る。図式の **パラメータ** は
  1. ソート変数 `'a, …`
  2. 文の自由変数（型つき）
  3. 文の局所関数記号（関数記号でだけ具体化できる）
  4. 文の局所述語記号（v2.0 では同じ名前でしか使えない）
- `Thm(名前, σs, ts)` の結論は、図式の仮定 `h₁ … hₖ` と結論 φ を `h₁ → … → hₖ → φ` にし、
  パラメータに σs・ts を代入したもの。
- **定義**（`def P(x₁:σ₁, …) := φ`）は φ の自由変数が引数だけで、P がまだ使われていないときに限り許す。
  定義は **保存的拡大**（定義を足しても、定義を使わない命題の証明可能性は変わらない）。
- **局所記号**：定理の証明は、文に現れない新しい局所記号を使ってよい（新しい定数を導入するのは保存的）。

## 8.1 kernel が保証すること・しないこと

kernel が保証するのは「**kernel が受け取った文**（型のついた論理式）が、上の規則・公理から導ける」ことまで。
ソースの文を parser が正しく読んだか、`notation` が紛らわしくないかは、人が文の表示を見て確かめる。
kernel のほかに、`src/syntax.rs` の代入・自由変数の計算（`subst`・`subst_many`・`free_vars`・
`instantiate`・`rename_fn`・`map_sorts`）も信頼の土台に入る。

## 9. v2.0 に含めないもの

- λ 抽象・関数型の値・関数変数の量化（v2.1）。したがって `(a + b) ⟶ (α + β)` のように
  **数列の和を引数に渡すことはできない**（v1 は各点ごとの読み替えで通していたが、仕様の裏づけがなかった）。
- 局所述語記号への論理式の代入（二階の図式の具体化）。
- 集合（`∈`・`⊂`）、商、利用者定義のソート。

## 10. 表層の構文と証明項の対応

| 表層 | 証明項 |
|---|---|
| `Fix x \| h` | `AllI(x, σ, ImpI(h, …))` |
| `assume h` | `ImpI` |
| `by_contra h` | `Raa` |
| `Obtain x, h₁, h₂ : e` | `ExE(e, x, h, Cut(h₁, …, AndE(…), Cut(h₂, …)))` |
| `have h : φ := j` | `Cut(h, φ, j, …)` |
| `suffices ψ := j` | `ImpE(j, …)` |
| `choose t` / `choose t, j` | `ExI` / `ExI(…, AndI(j, …))` |
| `choose left` / `right` | `OrI` |
| `cases h` | `OrE` |
| `induction n` | `Ind`（文脈の変数なら `AllE(Ind(…), n)`） |
| `let x := t` | `Let` |
| `contradiction h k` | `BotE(φ, ImpE(k, h))` |
| `unfold …` | なし（§6 の δ で kernel は同一視する） |
| `∴ φ` | なし（elab が読みやすさのために確かめるだけ） |
| `Obtain N(ε)` の依存の注釈 | なし（elab が確かめるだけ） |
| 連鎖 `a = b by … < c by …` | `Trans`（足りないときは `LinArith`） |
| `refl` / `ring` / `linarith` / `decide` / `sorry` | `Refl` / `Ring` / `LinArith` / `Decide` / `Sorry` |
| `EQ2(h, hφ)` | `Subst`（elab が φ を見つける） |
| `h.left` / `h.right` | `AndE` |
| `or.left(p)` / `or.right(p)` | `OrI` |
| 定理名・公理名の適用 `t(a, b)` | `Thm` に `AllE`・`ImpE` を重ねる |
