# Narfi 言語仕様書

**バージョン 0.3.2**

Narfi（Natural Annotated Reasoning Forward Interactive、ナーフィ）は自然演繹に基づく証明記述言語である。
インタプリタが検証可能な言語A（核言語）と、
人間が書きやすい言語B（糖衣言語）の二層からなる。
言語Bは機械的に言語Aへ展開される。

**v0.3.2 変更点（v0.3.1 から）**
- `by_contra h : ¬φ` → `by_contra h`（型注釈廃止、`¬goal` を自動推論）
- `by_contra` と `assume` の役割を明確に分離
- `choose` を ∨導入に拡張：`choose left` / `choose right`
- `or.left` / `or.right` を組み込み補題名として追加
- `ring` を純粋 oracle（引数なし）に限定、`linarith(j₁, j₂, ...)` を追加
- `cases` の `pattern` を定義（`left name` / `right name`）
- §8.4 の例を修正（`assume` 使用、`linarith` 使用）
- `Prop` を型体系に追加
- §8.7 に ∨ の例を追加

## 1. 基本概念

### 1.1 二層構造

```
言語B（人間が書く）
    ↓ 機械的展開（§6）
言語A（インタプリタが検証する）
    ↓ 推論規則の適用（§4）
検証完了
```

### 1.2 論理式の言語（両言語共通）

論理式は証明ステップとは完全に分離した言語で書かれる。
∀, ∃ はこの層にのみ現れ、証明ステップには現れない。

```
φ, ψ ::=
    | P(t₁, ..., tₙ)          -- 原子命題（P は述語記号、tᵢ は項）
    | φ → ψ                    -- 含意
    | φ ∧ ψ                    -- 連言
    | φ ∨ ψ                    -- 選言
    | ∀x : τ. φ               -- 全称量化
    | ∃x : τ. φ               -- 存在量化
    | ⊥                        -- 矛盾
    | ¬φ                       -- 否定（¬φ は φ → ⊥ の略記）

t ::=
    | x                        -- 変数
    | f(t₁, ..., tₙ)          -- 関数適用
    | λx. t                    -- λ抽象（項レベルのみ）
    | c                        -- 定数

τ ::=
    | ℕ | ℝ | ℤ | ...          -- 基本型
    | Prop                     -- 命題の型（述語の値域）
    | τ → τ                    -- 関数型
```

述語 `P` の型は `τ → Prop`（または `τ₁ → ... → τₙ → Prop`）。

### 1.3 文脈

文脈 Γ は名前と型（またはクラス・命題）の対のリスト。

```
Γ ::= ε | Γ, x : τ | Γ, h : φ | Γ, x := t
```

`:` は「満たすべき性質」を表す。
`x : ℕ` は「x は ℕ の元」、`h : φ` は「h は φ の証拠」。

### 1.4 判断

```
Γ ⊢ φ
```

「文脈Γのもとでφが証明可能」という判断を表す。

## 2. 公理系

### 2.1 等号公理

```
EQ1 : ∀x : τ. x = x
EQ2 : ∀x : τ. ∀y : τ. x = y → ∀φ : τ → Prop. φ(x) → φ(y)
```

EQ2 の使い方：`EQ2(h, hφ)` と書いたとき、

- `h : x = y`
- `hφ : φ(x)`
- 結論：`φ(y)`

φ は goal と hφ からインタプリタが単一化で推論する。
一意に推論できない場合のみ λ抽象で明示：`EQ2(h, λz. z = x, hφ)`。

EQ1, EQ2 から以下が導出される：

```
eq.symm  : x = y → y = x
eq.trans : x = y → y = z → x = z
congr.S  : x = y → S(x) = S(y)
```

### 2.2 ペアノ公理（二階）

原始記号：`0 : ℕ`、`S : ℕ → ℕ`

```
PA1 : ∀n : ℕ. S(n) ≠ 0
PA2 : ∀m : ℕ. ∀n : ℕ. S(m) = S(n) → m = n
PA3 : ∀S ⊆ ℕ. (0 ∈ S ∧ ∀k : ℕ. k ∈ S → S(k) ∈ S) → S = ℕ
```

### 2.3 加法の定義

```
add.zero : ∀n : ℕ. n + 0 = n
add.succ : ∀n : ℕ. ∀m : ℕ. n + S(m) = S(n + m)
```

### 2.4 乗法の定義

```
mul.zero : ∀n : ℕ. n · 0 = 0
mul.succ : ∀n : ℕ. ∀m : ℕ. n · S(m) = n · m + n
```

### 2.5 順序の定義

```
m ≤ n  :⟺  ∃k : ℕ. m + k = n
m < n  :⟺  m ≤ n ∧ m ≠ n
```

### 2.6 組み込み補題

以下は公理ではなく、自然演繹の規則から直接得られる組み込み補題名として使用できる。

```
-- 選言
or.left  : φ → φ ∨ ψ        -- ∨導入（左）
or.right : ψ → φ ∨ ψ        -- ∨導入（右）

-- oracle（決定手続き）
ring     : （引数なし）環の等式を自動証明
linarith : （引数あり可）線形算術を自動証明
decide   : （引数なし）有限領域の命題を自動証明
```

## 3. 言語A：核言語

### 3.1 構文（BNF）

```
proof    ::= "thm" name ":" context "⊢" formula newline block

context  ::= ε
           | context_entry ("," context_entry)*

context_entry ::= name ":" type       -- 変数（x : ℕ）
               | name ":" formula     -- 仮定（h : φ）

block    ::= indent stmt+ dedent

stmt     ::=
    | let_def
    | assume_intro
    | fix_intro
    | obtain_elim
    | have_step
    | suffices_step
    | contra_intro
    | contradiction_step
    | induction_step
    | cases_step
    | chain_step
    | choose_step
    | just_step

-- 定義導入（計算操作・論理状態不変）
let_def  ::= "let" name ":=" term newline

-- →導入（assumeスコープ：脱出で φ → goal が結論）
assume_intro ::= "assume" name ":" formula newline block

-- ∀導入（Fixスコープ：脱出で ∀x:τ. goal が結論）
fix_intro    ::= "Fix" name ":" type newline block

-- ∃除去（最外の∃を解除、x と hx を現スコープに追加）
obtain_elim  ::= "Obtain" name "," name ":" just newline

-- 前向きステップ
have_step    ::= "have" name ":" formula ":=" just newline

-- goal の後退
suffices_step ::= "⇐" formula ":=" just newline

-- 背理法（古典論理）
-- h の型は ¬(current goal) を自動推論
-- goal が φ のとき h : ¬φ を文脈に追加、スコープ内 goal は ⊥
contra_intro  ::= "by_contra" name newline block

-- 矛盾の明示
contradiction_step ::= "contradiction" name name newline

-- 帰納法
induction_step ::= "induction" name newline
                   "Case zero" ":" newline block
                   "Case succ" name "," name ":" newline block

-- 場合分け（∨除去）
cases_step ::= "cases" name newline or_case or_case
or_case    ::= "Case" or_pattern ":" newline block
or_pattern ::= "left" name | "right" name

-- 不等式連鎖（言語Aでは have の列として展開済み）
chain_step ::= term rel term "by" just newline
               (rel term "by" just newline)*

-- ∃導入 / ∨導入（goal を書き換えるのみ、スコープ不変）
choose_step ::= "choose" choice newline
choice      ::= term | "left" | "right"

-- goal を直接閉じる
just_step  ::= just newline

rel ::= "≤" | "<" | "=" | "≥" | ">"
```

### 3.2 justification（根拠）の構文

```
just ::=
    | name                        -- 文脈中の仮定名・定理名・oracle名
    | name "(" just* ")"          -- 適用（oracle への引数渡しも含む）
    | just "," just               -- 複数の根拠の組み合わせ（∧導入に使用）
    | "refl"                      -- 反射律（t = t）
```

**oracle 名として認識されるもの**：`ring`、`linarith`、`decide`

- `ring` — 引数なし。環の等式を決定手続きで検証する
- `linarith(j₁, j₂, ...)` — 引数あり可。文脈の仮定に加えてヒントとして渡す
- `decide` — 引数なし。有限領域の命題を全列挙で検証する

`or.left(j)`、`or.right(j)` は `name(just*)` の形で使用できる組み込み補題名（§2.6）。

## 4. 推論規則

### 4.1 構造規則

**弱化（Weakening）**
$$\frac{\Gamma \vdash \varphi}{\Gamma, x : \tau \vdash \varphi}$$

**文脈参照**
$$\frac{(h : \varphi) \in \Gamma}{\Gamma \vdash \varphi}$$

### 4.2 含意

**→導入（assumeスコープ脱出時）**
$$\frac{\Gamma,\, h : \psi \vdash \varphi}{\Gamma \vdash \psi \to \varphi}$$

**→除去（justificationとして使用）**
$$\frac{\Gamma \vdash \psi \to \varphi \quad \Gamma \vdash \psi}{\Gamma \vdash \varphi}$$

### 4.3 全称量化

**∀導入（Fixスコープ脱出時）**
$$\frac{\Gamma,\, x : \tau \vdash \varphi(x)}{\Gamma \vdash \forall x : \tau.\, \varphi(x)} \quad (x \notin FV(\Gamma))$$

**∀除去（justificationとして使用）**
$$\frac{\Gamma \vdash \forall x : \tau.\, \varphi(x) \quad \Gamma \vdash t : \tau}{\Gamma \vdash \varphi(t)}$$

### 4.4 存在量化

**∃導入（`choose t`）**

goal が `∃x : τ. φ(x)` のとき、`choose t` により goal を `φ(t)` に変更する。

$$\frac{\Gamma \vdash t : \tau \quad \Gamma \vdash \varphi(t)}{\Gamma \vdash \exists x : \tau.\, \varphi(x)}$$

**∃除去（`Obtain x, hx : e`）**

`e` の型が `∃x : τ. φ(x)` であるとき、`x : τ` と `hx : φ(x)` を文脈に追加する。
解除されるのは最外の∃のみ。ネストした∃は複数回のObtainが必要。

$$\frac{\Gamma \vdash \exists x : \tau.\, \varphi(x)}{\Gamma,\, x : \tau,\, hx : \varphi(x) \vdash \psi} \implies \Gamma \vdash \psi \quad (x \notin FV(\psi))$$

### 4.5 連言・選言

**∧導入**（justification `j₁, j₂` で対応）
$$\frac{\Gamma \vdash \varphi \quad \Gamma \vdash \psi}{\Gamma \vdash \varphi \land \psi}$$

**∧除去**

`h : φ ∧ ψ` に対して `h.left : φ`、`h.right : ψ` でアクセス。

**∨導入**

goal が `φ ∨ ψ` のとき：

- `choose left` → goal を `φ` に変更
- `choose right` → goal を `ψ` に変更

`have` ステップで使う場合は組み込み補題名を使用：

```narfi
have h : φ ∨ ψ := or.left(j)    -- j : φ
have h : φ ∨ ψ := or.right(j)   -- j : ψ
```

$$\frac{\Gamma \vdash \varphi}{\Gamma \vdash \varphi \lor \psi} \quad \frac{\Gamma \vdash \psi}{\Gamma \vdash \varphi \lor \psi}$$

**∨除去（`cases h`）**

`h : φ ∨ ψ` に対して：

```narfi
cases h
  Case left h₁:
    -- h₁ : φ が文脈に入る、goal は変わらない
  Case right h₂:
    -- h₂ : ψ が文脈に入る、goal は変わらない
```

$$\frac{\Gamma \vdash \varphi \lor \psi \quad \Gamma, h_1 : \varphi \vdash \chi \quad \Gamma, h_2 : \psi \vdash \chi}{\Gamma \vdash \chi}$$

### 4.6 矛盾・背理法

**⊥除去（Ex falso）**
$$\frac{\Gamma \vdash \bot}{\Gamma \vdash \varphi}$$

**矛盾（contradiction）**
$$\frac{\Gamma \vdash \varphi \quad \Gamma \vdash \neg\varphi}{\Gamma \vdash \bot}$$

**否定の直接証明（`assume`）**

goal が `¬φ`（= `φ → ⊥`）のとき、`assume h : φ` で証明する。
これは含意の →導入（§4.2）と同じ規則で処理される。

```narfi
-- goal: ¬φ（= φ → ⊥）
assume h : φ
  -- goal: ⊥ を示す
```

**背理法（古典論理、`by_contra`）**

goal が否定でない `φ` のとき、`by_contra h` で h:¬φ を仮定して ⊥ を導く。
h の型は `¬(current goal)` を自動推論する（型注釈不要）。

$$\frac{\Gamma,\, h : \neg\varphi \vdash \bot}{\Gamma \vdash \varphi}$$

**使い分けの原則**：

| 状況 | 使う命令 |
|------|---------|
| goal が `¬φ` または `φ → ψ` | `assume h : φ`（→導入） |
| goal が否定でない `φ`、古典論理が必要 | `by_contra h` |

### 4.7 定義（let）

`let x := t` により文脈に `x := t` と `x = t` が追加される。
論理操作ではなく、goal・スコープに変化を与えない。

### 4.8 Suffices

`⇐ ψ := j` において `j` が `ψ → (現在のgoal)` の証拠であるとき、
goalを ψ に変更する。

### 4.9 帰納法（自然数）

$$\frac{\Gamma \vdash \varphi(0) \quad \Gamma,\, k : \mathbb{N},\, \text{IH} : \varphi(k) \vdash \varphi(k+1)}{\Gamma \vdash \forall n : \mathbb{N}.\, \varphi(n)}$$

## 5. スコープ規則

スコープはインデントで表現される。

| 命令 | スコープ | 脱出時の結論 |
|------|---------|------------|
| `assume h : φ` | あり | `φ → (内部goal)` |
| `Fix x : τ` | あり | `∀x:τ. (内部goal)` |
| `by_contra h` | あり | 内部goalが ⊥ → 外部goalが証明される |
| `Obtain x, hx : e` | なし | x, hx を現スコープに追加 |
| `choose t / left / right` | なし | goal を書き換えるのみ |

**初期goal**：`thm name : Γ ⊢ φ` の `φ` が証明開始時の goal。

**自由変数制約**：
- `Fix x : τ` のスコープ脱出時、`x ∉ FV(Γ)` でなければ型エラー
- `Obtain x, hx : e` 後、`x ∉ FV(goal)` でなければ型エラー

## 6. 言語B：糖衣言語

言語Bは言語Aへの機械的な展開規則を持つ。

### 6.1 型推論によるクラス省略

`Fix x` と書いた場合、goalの `∀x:τ.φ(x)` から `τ` を推論する。
推論不能な場合は明示必須（型エラー）。

### 6.2 x.prop による性質参照

`Obtain x : e` において `e : ∃x:τ. φ(x)` のとき、
展開後は `Obtain x, x_prop : e` となり、
言語B中の `x.prop` は `x_prop` に置換される。
`h : φ ∧ ψ` に対して `h.left`、`h.right` も同様。

### 6.3 不等式連鎖の展開

```
-- 言語B
t₀
  rel₁ t₁   by j₁
  rel₂ t₂   by j₂
  rel₃ t₃   by j₃
```

は言語Aの以下に展開される：

```
have _h1 : t₀ rel₁ t₁ := j₁
have _h2 : t₁ rel₂ t₂ := j₂
have _h3 : t₂ rel₃ t₃ := j₃
have _hchain : t₀ rel* t₃ := trans(_h1, _h2, _h3)
```

`rel*` は推移律で合成した関係。合成規則：

| rel₁ | rel₂ | rel* |
|------|------|------|
| = | = | = |
| = | ≤ | ≤ |
| ≤ | = | ≤ |
| ≤ | ≤ | ≤ |
| = | < | < |
| < | = | < |
| < | ≤ | < |
| ≤ | < | < |
| < | < | < |

### 6.4 assume の型推論

goalが `φ → ψ` のとき、`assume h` と書けば `assume h : φ` に展開される。

### 6.5 EQ2 の φ 省略

`EQ2(h, hφ)` と書いたとき、φ はgoalと hφ からインタプリタが単一化で推論する。

### 6.6 Fix の行内条件付け（§12）

goalが `∀x:τ. φ → ψ` の形のとき：

```
Fix x | h : φ       →   Fix x : τ
  <ψ のブロック>           assume h : φ
                              <ψ のブロック>
```

## 7. インタプリタの動作

1. **パース**：言語B → 言語A へ展開（§6の規則を適用）
2. **型検査**：各stmtの型が整合しているか確認
3. **推論規則の適用**：各stmtが§4の規則のどれかに対応するか確認
4. **goalの追跡**：
   - 初期goalは `thm` の `⊢ φ`
   - スコープ開始時にgoalをスタックに積む
   - スコープ脱出時にスタックから取り出し、規則に従って新goalを生成
5. **justificationの検証**：`j` が現goalへの証拠として文脈中に存在するか確認
6. **oracle検証**：`ring`、`linarith`、`decide` を認識し決定手続きに委譲
7. **単一化**：EQ2 の φ 推論など、型推論が必要な箇所で単一化を行う

## 8. 完全な例

### 8.1 等号の基本補題

```narfi
thm eq.symm :
  h : x = y
  ⊢ y = x

EQ2(h, refl)
```

```narfi
thm eq.trans :
  hxy : x = y, hyz : y = z
  ⊢ x = z

EQ2(hyz, hxy)
```

```narfi
thm congr.S :
  h : x = y
  ⊢ S(x) = S(y)

EQ2(h, refl)
```

### 8.2 加法の基本性質

```narfi
thm add.zero_left :
  ⊢ ∀n : ℕ. 0 + n = n

Fix n
  induction n
    Case zero:
      add.zero(0)
    Case succ k, IH : 0 + k = k:
      have h1 : 0 + S(k) = S(0 + k) := add.succ(0, k)
      have h2 : S(0 + k) = S(k)     := congr.S(IH)
      eq.trans(h1, h2)
```

### 8.3 言語Bで書いた極限の加法性

```narfi
thm conv.add :
  conv_a : a_n → α, conv_b : b_n → β
  ⊢ a_n + b_n → α + β

Fix ε
  assume hε : ε > 0
    Obtain N₁, hN₁ : conv_a(ε/2, pos_half(hε))
    Obtain N₂, hN₂ : conv_b(ε/2, pos_half(hε))
    let N := max(N₁, N₂)
    Fix n
      assume hn : n ≥ N
        |(a_n+b_n)-(α+β)|
          ≤ |a_n-α| + |b_n-β|   by triangle
          < ε/2 + ε/2            by hN₁(ge.max.left(hn)),
                                    hN₂(ge.max.right(hn))
          = ε                    by ring
```

### 8.4 背理法：√2 は無理数

```narfi
thm sqrt2.irrational :
  ⊢ ¬∃p : ℕ. ∃q : ℕ. q ≠ 0 ∧ coprime(p, q) ∧ p² = 2·q²

-- goal: ¬∃p... = ∃p... → ⊥ なので assume で十分（by_contra 不要）
assume H : ∃p : ℕ. ∃q : ℕ. q ≠ 0 ∧ coprime(p, q) ∧ p² = 2·q²
  Obtain p, hp : H
  Obtain q, hq : hp
  have hqne  : q ≠ 0           := hq.left
  have hcop  : coprime(p, q)    := hq.right.left
  have heq   : p² = 2·q²        := hq.right.right
  have hp_even : even(p)        := even.sq.implies.even(even.of.eq(heq))
  Obtain k, hk : hp_even
  -- hk : p = 2·k
  have hq_sq : q² = 2·k²       := linarith(heq, hk)
  have hq_even : even(q)        := even.sq.implies.even(even.of.eq(hq_sq))
  have hncop : ¬coprime(p, q)   := both.even.not.coprime(hp_even, hq_even)
  contradiction hcop hncop
```

### 8.5 帰納法：加法単位元

```narfi
thm add.zero_right :
  ⊢ ∀n : ℕ. n + 0 = n

induction n
  Case zero:
    add.zero(0)
  Case succ k, IH : k + 0 = k:
    have h : (k + 1) + 0 = (k + 0) + 1 := add.succ(k, 0)
    eq.trans(h, congr.S(IH))
```

### 8.6 ∃導入：choose の使用例

```narfi
thm exists_double :
  ⊢ ∀n : ℕ. ∃m : ℕ. m = n + n

Fix n
  choose n + n
  refl
```

### 8.7 選言：∨ の証明と場合分け

```narfi
-- ∨導入（choose）
thm or_intro_example :
  h : P
  ⊢ P ∨ Q

choose left
P   -- goal は P。h で閉じる
```

```narfi
-- ∨除去（cases）
thm or_elim_example :
  h : P ∨ Q, hpq : P → R, hqr : Q → R
  ⊢ R

cases h
  Case left h₁:
    hpq(h₁)
  Case right h₂:
    hqr(h₂)
```

```narfi
-- by_contra：goal が否定でない場合の古典的背理法
thm dne :
  h : ¬¬P
  ⊢ P

by_contra hn
  -- hn : ¬P が文脈に追加される
  -- goal: ⊥
  h(hn)
```

## 10. 命名規則

### 10.1 定理・補題名

```
add.zero      -- 加法：ゼロ
add.succ      -- 加法：後者
eq.symm       -- 等号：対称律
eq.trans      -- 等号：推移律
congr.S       -- 後者関数の合同
mul.comm      -- 乗法：交換法則
le.antisymm   -- 順序：反対称律
```

### 10.2 予約語の大文字・小文字

**基準**：その行の実行によって「未定の（任意の/存在するが具体的に分からない）対象」が
文脈に追加されるなら大文字、すべて既知の対象のみを扱うなら小文字。

```
未定の対象を扱う（大文字）:
  Fix x : τ              -- ∀導入：goalから未定の x を取り出す
  Obtain x, hx : e       -- ∃除去：前提から未定の x を取り出す
  Case succ k, IH : ...  -- 帰納法ケース：未定の k, IH を追加
  Case left h₁ / right h₂ -- ∨除去：未定の h₁ / h₂ を追加

既知の対象のみを扱う（小文字）:
  let x := t             -- 定義（計算操作、論理状態は不変）
  assume h : φ           -- →導入（h は仮定された証拠）
  choose t / left / right -- ∃・∨導入：既知のwitness/方向を指定
  have h : φ := j        -- 前向きステップ
  by_contra h            -- 背理法（h の型は自動推論）
  induction n            -- 既存の n に対する帰納法
  cases h                -- 既存の h に対する場合分け
```

**例外**：`induction`/`cases` ブロック内の `Case` は常に大文字（新しい変数を追加するため）。

## 11. エラー条件

| エラー | 原因 |
|--------|------|
| 型エラー | `Obtain x, hx : e` において `e` の型が `∃x:τ.φ` でない |
| 型エラー | `choose t` において現goalが `∃x:τ.φ(x)` でない |
| 型エラー | `choose left/right` において現goalが `φ ∨ ψ` でない |
| 型エラー | `cases h` において `h` の型が `φ ∨ ψ` でない |
| 型エラー | `by_contra h` において current goal が ¬φ（= φ→⊥）の形のとき（`assume` を使うべき） |
| 自由変数エラー | `Fix x` スコープ脱出時に `x ∈ FV(Γ)` |
| 自由変数エラー | `Obtain x` 後 `x ∈ FV(goal)` |
| goalの不一致 | `⇐ ψ := j` において `j` が `ψ → goal` の証拠でない |
| 矛盾の不一致 | `contradiction h₁ h₂` において `h₁ : φ`, `h₂ : ¬φ` でない |
| 推論不能 | 言語Bの型省略が一意に推論できない |
| 単一化失敗 | EQ2 の φ が goalと hφ から一意に定まらない |

## 12. 今後の課題（v0.4以降で検討）

### 12.1 tunnel：基本変換の双方向適用

`eq.symm`、`x>y ↔ y<x`、`x<y ↔ x≤y∧x≠y` のような基本的な変換を、
明示的に書かずに自由に行き来する（「トンネルを掘る」）。

登録された双方向書き換え規則（rewrite rules）を just の単一化時に自動適用する。

**懸念**：規則を増やすほど「楽」になるが、増やしすぎると
「何が起きたか分からない」状態になる。
規則集合の濃さは「読者が自明と感じるレベル」に応じて段階的に調整できるべき。

### 12.2 structure / instance 機構

```
structure preorder(R : τ → τ → Prop):
  refl  : ∀x. R(x, x)
  trans : ∀x y z. R(x,y) → R(y,z) → R(x,z)

instance eq_is_preorder : preorder(=) :=
  { refl := EQ1, trans := eq.trans }

instance le_is_preorder : preorder(≤) :=
  { refl := le.refl, trans := le.trans }
```

`tunnel` はgoalの主要記号からインスタンステーブルを検索し、該当する構造の一般規則を適用する。

### 12.3 有限集合・総積（FinSet）

`∏_{p ≤ M} p`（M以下の全素数の積）のような有限集合上の総積への対応。
FinSet を PA の上に正式に構築するのは別プロジェクトとして保留。
