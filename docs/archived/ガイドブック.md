# Narfi インタープリタ実装ガイドブック

---

## 0. 鳥瞰図：このインタープリタは何をするか

通常のインタープリタは「プログラムを実行して値を出す」。Narfi は違う。

```
通常: ソース → 実行 → 値（42, "hello", ...）
Narfi: ソース → 検証 → Ok（証明は正しい）| Err（ここが間違い）
```

「実行」の代わりに「検証」をする。これが**証明チェッカー**。

パイプライン：

```
source.narfi
    ↓  Lexer      文字列 → トークン列
Vec<Token>
    ↓  Parser     トークン列 → 構文木（AST）
AST
    ↓  Checker    証明の正しさを検証
Ok(()) | Err(CheckError)
```

3つのステージ。順番に作る。

---

## 用語

| 用語 | 意味 |
|------|------|
| **statement（文、stmt）** | 証明の1ステップ。`assume h : φ` や `by j` など |
| **expression（式）** | 値を返す式。`x + 1` や `eq.trans(h1, h2)` など |
| **AST** | Abstract Syntax Tree（抽象構文木）。ソースを木構造で表したもの |
| **トークン** | 字句解析後の最小単位。`by`、`h1`、`(`、`)` など |
| **ゴール** | 今証明すべき命題 |
| **文脈** | 今使える仮定・変数・定義のリスト |

## 1. AST：「何を表すか」を最初に決める

コードより先に型定義を書く。型が決まれば残りは「型を満たすコードを書く」作業になる。

### なぜ木（Tree）か

`0 + n = n` という式を文字列のままでは扱いにくい。木にすると：

```
    =
   / \
  +   n
 / \
0   n
```

Rust ではこれを `enum` で表す。

### 再帰型と Box

`Formula` は自分自身を含む（`Implies(Formula, Formula)` など）。
Rust では再帰型のサイズが決まらないため `Box<T>`（ヒープ上へのポインタ）が必要：

```rust
// ❌ コンパイルエラー（サイズ不明）
enum Formula { Implies(Formula, Formula) }

// ✅ OK（Box のサイズはポインタ1個分で固定）
enum Formula { Implies(Box<Formula>, Box<Formula>) }
```

### Narfi の AST

## 2. レキサー：文字列 → トークン列

### トークンとは

```
"(h1) 0 + S(k) = S(0 + k)   by add.succ(0, k)"
```

を人間が読むとき自然に区切るもの：

```
LParen  Ident("h1")  RParen  ...  By  Ident("add.succ")  LParen  ...
```

これが**トークン**。レキサーはこの区切り作業をする。

### トークンの定義


### インデント処理（最大の難所）

```narfi
assume h : φ
  (h1) A by j    ← ここで Indent
  by j2
                 ← ここで Dedent（次の行のインデントが浅くなったとき）
```

Python と同じ問題。**スタック**で解決する：

```rust
pub struct Lexer {
    chars: Vec<char>,
    pos: usize,
    indent_stack: Vec<usize>,   // 現在のインデントレベルを追跡
}

impl Lexer {
    // 行頭のスペース数を数えて INDENT/DEDENT を生成する
    fn process_indent(&mut self, new_level: usize, out: &mut Vec<Token>) {
        let current = *self.indent_stack.last().unwrap_or(&0);
        if new_level > current {
            self.indent_stack.push(new_level);
            out.push(Token::Indent);
        } else if new_level < current {
            while *self.indent_stack.last().unwrap_or(&0) > new_level {
                self.indent_stack.pop();
                out.push(Token::Dedent);
            }
            // new_level がスタック上に存在しない場合はエラー（不正なインデント）
        }
        // new_level == current → 変化なし（同じレベルの続き）
    }
}
```

### 識別子の認識

Unicode 文字を許すので `char::is_alphabetic()` を使う：

```rust
fn scan_ident(&mut self) -> Token {
    let mut s = String::new();
    while let Some(&c) = self.chars.get(self.pos) {
        if c.is_alphanumeric() || c == '_' || c == '\'' {
            s.push(c);
            self.pos += 1;
        } else if c == '.' {
            // 次が識別子文字なら名前空間ドット（eq.trans など）
            if self.chars.get(self.pos + 1).map_or(false, |c| c.is_alphabetic()) {
                s.push(c);
                self.pos += 1;
            } else {
                break;
            }
        } else {
            break;
        }
    }
    keyword_or_ident(s)
}

fn keyword_or_ident(s: String) -> Token {
    match s.as_str() {
        "thm"           => Token::Thm,
        "let"           => Token::LetLower,
        "Let"           => Token::LetUpper,
        "assume"        => Token::Assume,
        "by"            => Token::By,
        "by_contra"     => Token::ByContra,
        "contradiction" => Token::Contradiction,
        "induction"     => Token::Induction,
        "cases"         => Token::Cases,
        "case"          => Token::Case,
        "Take"          => Token::Take,
        "refl"          => Token::Refl,
        "ring"          => Token::Ring,
        "linarith"      => Token::Linarith,
        "decide"        => Token::Decide,
        // ... 君が残りを埋める
        _               => Token::Ident(s),
    }
}
```

**君が書く部分** — 数学記号の認識：

```rust
fn scan_symbol(&mut self) -> Option<Token> {
    let c = self.chars[self.pos];
    let tok = match c {
        '∀' => Token::Forall,
        '∃' => Token::ExistsOp,
        '→' => Token::Arrow,
        '∧' => Token::And,
        '∨' => Token::Or,
        '¬' => Token::Not,
        // 君が埋める: ⊢ ⊥ ≤ ≥ ≠ ⟺ ⇐
        _   => return None,
    };
    self.pos += 1;
    Some(tok)
}
```

## 3. パーサー：トークン列 → AST

### 再帰下降の考え方

文法の各規則を、そのまま関数にする。

```
formula    → implies
implies    → or (→ implies)?        ← 右結合なので再帰呼び出し
or         → and (∨ and)*
and        → unary (∧ unary)*
unary      → ¬ unary | quantifier | atom
quantifier → ∀x:τ.φ | ∃x:τ.φ
atom       → P(t,...) | ⊥ | (formula)
```

これを Rust に翻訳する：

```rust
// src/parser.rs

pub struct Parser { tokens: Vec<Token>, pos: usize }

impl Parser {
    fn peek(&self) -> Option<&Token> { self.tokens.get(self.pos) }

    fn advance(&mut self) -> Option<Token> {
        let t = self.tokens.get(self.pos).cloned();
        if t.is_some() { self.pos += 1; }
        t
    }

    fn eat(&mut self, expected: &Token) -> bool {
        if self.peek() == Some(expected) { self.advance(); true } else { false }
    }

    fn expect(&mut self, expected: Token) -> Result<(), ParseError> {
        if self.eat(&expected) { Ok(()) }
        else { Err(ParseError::Expected(expected, self.peek().cloned())) }
    }

    fn expect_ident(&mut self) -> Result<String, ParseError> {
        match self.advance() {
            Some(Token::Ident(s)) => Ok(s),
            other => Err(ParseError::ExpectedIdent(other)),
        }
    }

    // ----- 論理式 -----

    pub fn parse_formula(&mut self) -> Result<Formula, ParseError> {
        self.parse_implies()
    }

    fn parse_implies(&mut self) -> Result<Formula, ParseError> {
        let lhs = self.parse_or()?;
        if self.eat(&Token::Arrow) {
            let rhs = self.parse_implies()?;   // 右結合: 自分を再帰呼び出し
            Ok(Formula::Implies(Box::new(lhs), Box::new(rhs)))
        } else {
            Ok(lhs)
        }
    }

    fn parse_or(&mut self) -> Result<Formula, ParseError> {
        let mut lhs = self.parse_and()?;
        while self.eat(&Token::Or) {
            let rhs = self.parse_and()?;
            lhs = Formula::Or(Box::new(lhs), Box::new(rhs));
        }
        Ok(lhs)
    }

        if self.eat(&Token::Not) {
            let inner = self.parse_unary()?;
            return Ok(Formula::Not(Box::new(inner)));

    fn parse_atom(&mut self) -> Result<Formula, ParseError> {
        if self.eat(&Token::Bottom) {
            return Ok(Formula::Bottom);
        }
        if self.eat(&Token::LParen) {
            let f = self.parse_formula()?;
            self.expect(Token::RParen)?;
            return Ok(f);
        }
        if let Some(Token::Ident(name)) = self.peek().cloned() {
            self.advance();
            if self.eat(&Token::LParen) {
                let args = self.parse_term_list()?;
                self.expect(Token::RParen)?;
                Ok(Formula::Atom(name, args))
            } else {
                Ok(Formula::Atom(name, vec![]))   // 引数なし原子命題
            }
        } else {
            Err(ParseError::UnexpectedToken(self.peek().cloned()))
        }
    }
```

## 4. 証明チェッカー：AST → Ok/Err

ここが Narfi の心臓部。最も面白い。

### 状態

```rust
// src/checker.rs

pub struct Checker {
    context: Vec<(String, ContextEntry)>,    // 今使える仮定・変数
    goal: Formula,                           // 今証明すべき命題
    frames: Vec<Frame>,                      // スコープのスタック
    theorems: HashMap<String, Formula>,      // 証明済み定理
}

#[derive(Debug, Clone)]
pub enum ContextEntry {
    Var(Type),              // x : ℕ（変数）
    Hyp(Formula),           // h : φ（仮定）
    Def(Term, Formula),     // let x := t  →  x = t も追加される
}

struct Frame {
    kind: FrameKind,
    saved_ctx_len: usize,   // スコープ脱出時に文脈をここまで巻き戻す
}

enum FrameKind {
    Assume  { antecedent: Formula },      // φ → ... の φ
    Let     { var: String, ty: Type },    // ∀x:τ. ... の x, τ
    ByContra,
}
```

### ゴールスタックの動き（ここが核心）

`assume h : φ` のブロックで何が起きるかを状態遷移で追う：

```
【開始前】
  goal    = φ → ψ
  context = Γ

  assume h : φ ──────────── Frame を積む
  【ブロック内】
    goal    = ψ              ← goal が変わる（φ → が剥がれた）
    context = Γ, h:φ         ← h が文脈に追加される

    (h1) A by j              ← A を検証、context に h1:A を追加
    by j2                    ← ψ を j2 で閉じる

  ──────────────────────── Frame を取り出す
【終了後】
  goal    = φ → ψ  （証明済み）
  context = Γ      （h は消える）
```

`Let x : τ` も同じ構造：

```
【開始前】goal = ∀x:ℕ. φ(x)

  Let x : ℕ ────── Frame を積む
  【ブロック内】
    goal    = φ(x)      ← ∀x:ℕ が剥がれた
    context = Γ, x:ℕ

    （証明...）
    by j                ← φ(x) を閉じる

  ────────────────── ∀x:ℕ. φ(x) が証明された
```

**これが自然に §5 の推論規則を実装している**：

$$\frac{\Gamma, h:\varphi \vdash \psi}{\Gamma \vdash \varphi \to \psi} \quad\quad \frac{\Gamma, x:\tau \vdash \varphi(x)}{\Gamma \vdash \forall x:\tau.\,\varphi(x)}$$

### チェッカーの実装

```rust
impl Checker {
    pub fn check_block(&mut self, stmts: &[Stmt]) -> Result<(), CheckError> {
        for stmt in stmts {
            self.check_stmt(stmt)?;
        }
        Ok(())
    }

    fn check_stmt(&mut self, stmt: &Stmt) -> Result<(), CheckError> {
        match stmt {

            Stmt::Assume { name, formula, body } => {
                // goal が φ → ψ の形か確認
                let inner_goal = match &self.goal.clone() {
                    Formula::Implies(ant, con) if ant.as_ref() == formula => {
                        *con.clone()
                    }
                    _ => return Err(CheckError::GoalMismatch {
                        expected: format!("{:?} → ...", formula),
                        got: format!("{:?}", self.goal),
                    }),
                };

                let saved = self.context.len();
                self.context.push((name.clone(), ContextEntry::Hyp(formula.clone())));
                self.frames.push(Frame {
                    kind: FrameKind::Assume { antecedent: formula.clone() },
                    saved_ctx_len: saved,
                });
                let old_goal = std::mem::replace(&mut self.goal, inner_goal);

                self.check_block(body)?;

                self.frames.pop();
                self.context.truncate(saved);
                self.goal = old_goal;
                Ok(())
            }

            Stmt::Close { just } => {
                let target = self.goal.clone();
                self.verify_just(just, &target)
                // goal はこれで「閉じた」
            }

            Stmt::ProofStep { label, formula, just } => {
                self.verify_just(just, formula)?;
                let name = label.clone().unwrap_or_else(|| "_".to_string());
                self.context.push((name, ContextEntry::Hyp(formula.clone())));
                Ok(())
            }

            Stmt::LetIntro { name, ty, body } => {
                // 君が書く
                // ヒント: Assume と同じ構造
                //   goal が ∀x:τ.φ(x) か確認
```

### justification の検証

`verify_just(just, target)` は「just が target を証明できるか」を確かめる：

```rust
    fn verify_just(&self, just: &Just, target: &Formula) -> Result<(), CheckError> {
        match just {
            Just::Name(name) => {
                // 文脈か定理環境から名前を引き、型が target と一致するか
                let formula = self.lookup(name)?;
                self.formula_matches(&formula, target)
            }

            Just::App(name, args) => {
                // name の型（関数型）を取得し、args を順に適用して target になるか
                // 例: eq.trans : x=y → y=z → x=z
                //     eq.trans(h1, h2) で x=z が得られるか確認
                let func_ty = self.lookup(name)?;
                self.apply_args(&func_ty, args, target)
            }

            Just::Refl => {
                // target が t = t の形か
                match target {
                    Formula::Atom(op, terms)
                        if op == "=" && terms.len() == 2 && terms[0] == terms[1] => Ok(()),
                    _ => Err(CheckError::ReflFailed(format!("{:?}", target))),
                }
            }

            Just::OrLeft(inner) => {
                // target が φ ∨ ψ の形か確認し、left 側を inner で検証
                match target {
                    Formula::Or(left, _) => self.verify_just(inner, left),
                    _ => Err(CheckError::ExpectedDisjunction),
                }
            }

            Just::OrRight(inner) => {
                // 君が書く（OrLeft と対称）
                todo!()
            }

            Just::Exists(witness, inner) => {
                // target が ∃x:τ.φ(x) の形か確認
                // φ の x を witness で置き換えた式を inner で検証
                match target {
                    Formula::Exists(var, _ty, body) => {
                        let substituted = subst_formula(body, var, witness);
                        self.verify_just(inner, &substituted)
                    }
                    _ => Err(CheckError::ExpectedExistential),
                }
            }

            Just::Pair(j1, j2) => {
                // target が φ ∧ ψ の形か確認
                // j1 で φ を、j2 で ψ を検証
                // 君が書く
                todo!()
            }

            Just::Ring     => self.check_ring(target),
            Just::Linarith => self.check_linarith(target),
            Just::Decide   => self.check_decide(target),
        }
    }

    fn lookup(&self, name: &str) -> Result<Formula, CheckError> {
        // 文脈を後ろから検索（新しい方が優先）
        for (n, entry) in self.context.iter().rev() {
            if n == name {
                return match entry {
                    ContextEntry::Hyp(f) => Ok(f.clone()),
                    ContextEntry::Var(_) => Err(CheckError::NotAProof(name.to_string())),
                    ContextEntry::Def(_, eq) => Ok(eq.clone()),
                };
            }
        }
        // 定理環境を検索
        self.theorems.get(name)
            .cloned()
            .ok_or_else(|| CheckError::NotFound(name.to_string()))
    }
```

### 代入（substitution）

`exists(0, add.zero(n))` で `∃k:ℕ. n+k=n` を証明するとき、
`k` を `0` で置換した `n+0=n` を検証する：

```rust
pub fn subst_formula(formula: &Formula, var: &str, replacement: &Term) -> Formula {
    match formula {
        Formula::Atom(pred, args) =>
            Formula::Atom(
                pred.clone(),
                args.iter().map(|t| subst_term(t, var, replacement)).collect(),
            ),

        Formula::Implies(a, b) =>
            Formula::Implies(
                Box::new(subst_formula(a, var, replacement)),
                Box::new(subst_formula(b, var, replacement)),
            ),

        Formula::Forall(x, ty, body) if x != var =>
            Formula::Forall(
                x.clone(), ty.clone(),
                Box::new(subst_formula(body, var, replacement)),
            ),

        Formula::Forall(x, _, _) if x == var =>
            formula.clone(),    // 同名の束縛変数は置換しない（変数捕獲を回避）

        // 君が書く: And, Or, Exists, Not, Bottom の各ケース
        _ => formula.clone(),
    }
}

pub fn subst_term(term: &Term, var: &str, replacement: &Term) -> Term {
    match term {
        Term::Var(x) if x == var => replacement.clone(),
        Term::Var(_)             => term.clone(),
        Term::App(f, args) =>
            Term::App(f.clone(), args.iter().map(|t| subst_term(t, var, replacement)).collect()),
        Term::Lambda(x, body) if x != var =>
            Term::Lambda(x.clone(), Box::new(subst_term(body, var, replacement))),
        Term::Lambda(_, _) =>
            term.clone(),   // 同名の束縛変数は置換しない
        Term::Const(_) => term.clone(),
    }
}
```
