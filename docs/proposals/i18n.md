# 提案：言語の核と自然言語の分離・定理の訳名

状態：検討中（v2.6 時点）。設計原則 7（言語の核は自然言語に依存しない）を実現するための案。

## 1. 今の状態

| 層 | 今 | 問題 |
|---|---|---|
| 予約語・記号 | ASCII の英語（`Fix`・`assume`・`by` など）＋数学記号 | なし |
| 日本語シュガー | パーサが日本語の文（「〜を任意にとって固定する」）を直接読む（`parser.rs` の `normalize_japanese_sugar`） | 構文に日本語が入っている |
| Prose・LaTeX の文章 | `prose.rs` に日本語の文が直接書かれている | ほかの言語にできない |
| エラーメッセージ | 日本語 | 同上 |

## 2. 案

- **言語の核**：予約語・記号・ファイルの書式は ASCII と数学記号だけ。全角文字は構文に使わない（名前・コメント・文字列の中は自由）。
- **表示の層（ロケール）**：日本語シュガー・Prose・エラーメッセージを「文の型紙」の表にする（例：`fix_hyp = "{h} : {φ} を満たす {x} を任意にとって固定する"`）。日本語（ja）を最初のロケールとし、英語（en）などを同じ表の形で足せる。
- **日本語シュガーを入力として読むこと**は、ロケールの型紙から逆に作る（型紙が 1 つなので、表示と入力がずれない）。

## 3. 定理の訳名

訳名は付けても付けなくてもよい。全角の括弧を予約語にしない形の案：

```
thm sum.add :
  @name ja "和の線形性"
  @name en "linearity of sums"
  ⊢ …
```

- `@name ロケール "名前"` は宣言の注釈（ASCII の構文で、中身は任意の言語）。
- Prose：「定理（和の線形性）」、根拠として使われた所は「和の線形性より」。LaTeX：`\begin{theorem}[和の線形性]`。エディタの日本語シュガーの表示では名前の代わりに訳名を出す。
- 訳名を別のファイル（`sum.ja.narfi` のような訳のファイル）に置く案もある（ライブラリ本体を言語ごとに変えずに済む）。
