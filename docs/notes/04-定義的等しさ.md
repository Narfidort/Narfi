# 4. 定義的等しさと定義

## 4.1 「同じ命題」とは何か

kernel は規則の前提が合っているかを比べる。たとえば →除去なら「φ → ψ の φ」と「渡された証明の命題」が
同じでなければならない。この「同じ」をどこまで広くとるかが **定義的等しさ**（仕様 §6）。

v2 は次の3つを同一視する（`src/kernel/env.rs` の `conv`）。

| 名前 | 内容 | 例 |
|---|---|---|
| α | 束縛変数の名前の違い | `∀x. P(x)` ≡ `∀y. P(y)` |
| δ（デルタ） | `def` の展開 | `is_lim(a, α)` ≡ `∀ε>0. ∃N:ℕ. …` |
| ζ（ゼータ） | `let` の展開 | `let N := max(N₁, N₂)` のもとで `n ≥ N` ≡ `n ≥ max(N₁, N₂)` |

名前は λ 計算の慣習から来ている（β・η もあるが、v2.0 には λ がないので使わない）。

## 4.2 定義的等しさと命題としての等号の違い

`N = max(N₁, N₂)` は命題で、証明が必要（`Refl` や書き換え `Subst` で使う）。
定義的に等しいものは **証明なしで** 入れ替えてよい。kernel が計算（展開）して確かめられるから。

どこまでを定義的等しさにするかは設計の選択で、広くすると便利だが kernel が複雑になる。
v2 は「展開すれば必ず止まる」ものだけにした。

- α：名前の付け替えだけ
- δ：定義は再帰しない（自分自身を使えない）ので、展開を繰り返せば必ず止まる
- ζ：let は前に置いたものしか参照できないので、必ず止まる

`ring` の等式（`ε/2 + ε/2 = ε`）は定義的等しさに入れていない。命題として `Ring` で証明する。

## 4.3 whnf：形を見る前の展開

∀除去では「命題が ∀ の形か」を見る。`conv_a : a ⟶ α` は `is_lim(a, α)` という述語で、見た目は ∀ ではない。
そこで **先頭の定義だけを** 展開してから形を見る。これを **弱頭部正規形**（weak head normal form, whnf）と呼ぶ。

```
is_lim(a, α)   →δ   ∀ε>0. ∃N:ℕ. ∀n≥N. |a(n) - α| < ε     ← 先頭が ∀ になった
```

中の `|a(n) - α| < ε` までは展開しない（必要になったら、そのとき展開する）。
これが v1 から引き継いだ「透過的な定義展開」の正体で、v2 では elab（`src/elab/unify.rs` の `whnf`）と
kernel（`src/kernel/env.rs` の `whnf`）が **同じ考え方を別々に実装** している。

## 4.4 定義による拡張は保存的

`def P(x) := φ(x)` を足すと、使える命題が増える。しかし「P を使わない命題」で新しく証明できるものは
増えない。これを **保存的拡大**（conservative extension）という。

理由の直感：P を使った証明があれば、P をすべて φ に書き換えれば P を使わない証明になる
（δ 展開で書き換えても規則は成り立つ）。だから定義を足しても矛盾は生まれない。

この議論が成り立つには、定義が **再帰しない** こと、本体の自由変数が **引数だけ** であることが必要。

- `def loop(x) := loop(x)` を許すと、展開が止まらない
- `def P(x) := x = y`（y は何？）を許すと、P(1) の意味が決まらない

kernel は定義を登録するとき（`src/kernel/mod.rs` の `add_def`）、本体を「その定義がまだない環境」で
型検査する。自分自身はまだ未定義なので、再帰した定義はここで止まる。

## 4.5 公理は保存的ではない

`axiom` で置いた命題は、保存的ではない（新しいことが証明できるようになる）。だから矛盾した公理を
置けば何でも証明できてしまう。kernel は、定理がどの公理に依存したかを **推移的に** 数えて報告する
（`〔公理: pos_half, triangle〕`）。prelude の等号・ペアノの公理は「核の公理」として報告しない。

`lib/analysis/real.narfi` の三角不等式などは、v2.0 では公理のまま。順序体の公理から証明して
公理を減らしていくのは今後の課題。

## 4.6 確かめてみる

```narfi
thm conv.unfold :
  a : ℕ → ℝ,
  h : a ⟶ α
  ⊢ ∀ε>0. ∃N:ℕ. ∀n≥N. |a(n) - α| < ε

unfold is_lim at h
h
```

`unfold` は elab の表示を変えるだけで、証明項は `Hyp(h)` のまま。kernel は δ で `h` の命題と結論を
同一視するので通る（`examples/limits.narfi`）。
