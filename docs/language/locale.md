# 言語仕様 v2.6 — ロケール（自然言語での読み）

設計原則 3（[../principles.md](../principles.md)）：言語の核（予約語・記号・ファイルの書式）は ASCII で、自然言語に依存しない。
日本語・英語などの「読み」は、ロケールの表（`narfi/src/locale/<名前>.txt`）だけが知っている。

## 表の書式

```
[statements]
=	Fix {x} | {h:id} : {f}	{h} : {f} を満たす {x} を任意にとって固定する
<	Fix {x} | {h:id} : {f}	{h} : {f} を満たす {x} を任意にとる

[declarations]
=	thm {rest}	定理 {rest}

[prose]
fix	任意の ${x}$ をとって固定する。
```

- `[statements]`・`[declarations]`：1 行が「標準の書き方 ⇄ この言語での書き方」の型紙の組（タブ区切り）。
  - `=` は読みも書きも（エディタの表示・ソースの変換）。標準の書き方ごとに、最初の `=` が使われる。
  - `<` は読むだけ。原則「書き方は 1 つ」により、今の表では使っていない（古い言い回しは残さない）。
  - `{名前}` は空でない文字列、`{名前:id}` は空白を含まない名前、`{名前:rel}` は `= < ≤ > ≥ ≠` のどれか。上から順に試す。
- `[prose]`：証明の文章（Prose・LaTeX）の型紙。`鍵<TAB>型紙`。`$…$` は数式。ない鍵は日本語の表から取る。
  - `A || B || C` と並べると、同じ文書の中で使うたびに順に替わる（「よって → ゆえに → したがって」）。同じ文書からはいつも同じ文章になる。

## どこで使われるか

| 使い道 | 向き |
|---|---|
| ソースの読み込み（パーサの前） | どのロケールで書かれた行も標準の書き方に直す（`=` と `<`） |
| エディタの読みの表示（下の言語のボタンでオン・オフ。言語は右下の歯車（Preferences、⌘,）） | 標準の書き方の行を、構造（数式の入力欄）を保ったまま読みで見せる（`=`）。ファイルは変わらない |
| ソースの変換（`narfi convert --ja`／`--en`） | 標準の書き方の行を読みで書く（`=`） |
| Prose・LaTeX | `[prose]` の型紙で文章にする |

読みと書きが同じ表から作られるので、どのロケールの変換も、変換して読み直すと元の証明に戻る（テストで確かめている）。

## 訳名（`@name`）

```
@name ja "和の線形性"
@name en "linearity of sums"
thm sum.add :
```

宣言の前に書く注釈（付けなくてもよい）。Prose の見出し・LaTeX の定理の題・根拠としての読み（「和の線形性 より」）に使われる。

## 新しいロケールを足すには

1. `narfi/src/locale/<名前>.txt` を作る（`ja.txt` を写して訳す）。読みは標準の書き方と区別がつくようにする（英語は文末に `.` や `:` を付けている）。
2. `narfi/src/locale/mod.rs` の `locales()` に足す。`scripts/build-site.sh` の `locales.js` を作る行にも足す。
3. `cargo test`（ロケールの往復のテスト）と、ソースの変換のテスト（`tests/ui.rs`）に足す。

エラーメッセージはまだ日本語だけ（今後、同じ形の表に移す）。
