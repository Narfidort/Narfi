# 記法の決まり（v2.11）

Narfi で数学の記法をどう扱うかの決まり。書き方の一覧は [syntax.md](syntax.md)、略記（notation）の仕組みは syntax.md §4.1。
設計の考え方は [../principles.md](../principles.md)。ここにない記法を足すときは、この決まりに照らして決める。

## 考え方
- 記法は数学の思考の道具なので、教科書どおりの見た目を保つ。見た目を変えると不自然になるものは変えない。
- 避けるのは「**同じ見た目で、意味が 2 つ以上ある**」こと（順序対と開区間、関数の値と像、`f^n` の冪と合成など）。慣習に頼って暗黙のまま使うことは受け入れない。
- Narfi は正しい証明を書くための道具なので、表記の揺れには付き合わず、Narfi が 1 つ決める。
- 書く手間はエディタ（補完・行の複製など）で補う。短く書きたいのは読むときなので、読みやすさを優先する。

## 分類と扱い
| 分類 | 中身 | 置き場所・決める人 | 進め方 |
|---|---|---|---|
| **B** | 大学以上の数学で広く共通の記法 | 組み込み・標準ライブラリの基礎（Narfi） | 最初に洗練する。B の中でも 1 対 1 にする |
| **F1** | 分野の慣習で、B とぶつからない記法 | 分野ごとの標準ライブラリ（Narfi。欲しいものから） | ライブラリを作るときに入れる |
| **F2** | 分野の慣習で、B とぶつかる記法 | 改変して F1 にする（Narfi） | 見た目を少し変える（例：合成の n 乗 `f^{∘n}`） |
| **R** | 研究で使われるマイナーな記法 | 利用者の `notation` | 仕組みは同じ。ぶつかればエラー |
| **P** | 個人が定義して使う記法 | 利用者の `notation` | 同上 |

## 同じ見た目を保ちつつ安全にする（これからの仕組み）
1. **型で 1 つに決まるなら、型で読み分ける。** 読み方の候補のうち型が合うのが 1 つならそれを使い、2 つ以上合うならエラーにする。直し方は型の明示（Tab で入れる）。
   例：`x ∈ (a, b)` は開区間（∈ の右は集合）、`p = (a, b)`（p は対）は順序対、`f(A)` は A が集合なら像。
2. **型でも区別できないものは、宣言で決める。** 例：関数の `f^n`（冪と合成はどちらも ℝ → ℝ）。宣言がなければエラー。
3. **決まった意味を見せる。** 読み方が選ばれた記法に薄い点線を付け、マウスを乗せると「順序対　(a, b) ∈ ℝ × ℝ」のように意味と核の形を出す。型の表示を切り替えるボタン（普段は切る）で、小さく型を添える。ファイルは変わらない。

1〜3 は、区間・像・合成などを定義するライブラリを作るときに実装する。それまでは、これらの記法は使えない（定義がない）。

## 決まったこと
| 記法 | 決定 | 状態 |
|---|---|---|
| ならば・同値 | `⇒`（`=>`）・`⇔`（`<=>`）。`→`（`->`）は関数の型と略記だけ | v2.11 |
| 定義 | 述語は `:⇔`（`:<=>`）、値は `:=` | v2.11 |
| 部分集合 | `⊂` は `⊆` と同じ。真部分集合は `⊊`（`subsetneq`） | v2.11 |
| 最大・最小 | `max{a, b}`・`min{a, b}`（`max(a, b)` は書かない） | v2.11 |
| 上付き | いつも冪。関数の添字には使わない（`F(i, j)`・`u(n)` と書く） | v2.11 |
| 数列の添字 | `a_n` は `a(n)`（a が `ℕ → σ` のとき。型で読む唯一の組み込み） | 済 |
| 補集合 | `A^∁` | 集合のライブラリで |
| 冪集合 | `𝒫(A)` | 同上 |
| 要素の個数 | `#A` | 同上 |
| ℕ | 0 を含む（`ℤ_{≥0}` も書ける） | 済 |
| `sin²x` | `(sin x)^2` と書く | 三角関数のライブラリで |
| 対数 | `log` が自然対数 | 指数・対数のライブラリで |
| 数列そのもの | `(a_n)_n` | 列のライブラリで |
| 転置 | `A^⊤` | 線形代数のライブラリで |
| 文字どうしの積 | ファイルは `a b`（空白）、表示は `ab`。行列の積も同じ | 字句解析に空白の情報が要るので、次の版以降 |
| 逆関数 | `f^{∘-1}`（合成の -1 乗。`f^{-1}` は数の逆数だけになる）の方向で検討 | 関数のライブラリで |
| 微分 | `\frac{d}{dx}`・`\frac{\partial}{\partial x}`・`\frac{d^n}{dx^n}` だけ（`f'`・`ḟ` は使わない） | 微分のライブラリで（下の課題を参照） |

## 保留・課題
- `(a, b)`（順序対・開区間）、`f(A)`・`f^{-1}(B)`（値・像・逆像）、`μ(A)`（測度）：上の 1（型で読み分け）で扱う。
- `f^n`（冪・合成）：上の 2（宣言）か `f^{∘n}`。
- `∃!`：単射・全域性などと一緒に、述語論理で定義して性質を調べる題材にする。記法は束縛つきの型紙で書ける見込み。
- 微分の `\frac{d}{dx} f(x)` の x は「微分のために束縛する x」と「評価する x」の 2 役で、今の型紙の決まり（束縛変数と入る所は別）では書けない。微分のライブラリを作るときに決まりを広げる。
- 多重指数の `α − β`・`β ≤ α`：上の 1 の延長（型で演算子の意味を決める）で扱えるかを検討する。
- 見送ったもの：記法を範囲（ブロック）ごとに開く仕組み（[../proposals/notation-scopes.md](../proposals/notation-scopes.md)）。仕組みが大きく、1〜3 で足りるため。
