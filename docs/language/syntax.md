# Narfi 言語仕様 v2.13 — 書き方（完全な一覧）

ソースに書けるものをすべて並べる。ここにない書き方は通らない。
論理の土台（型・推論規則・kernel）は [logic.md](logic.md)、設計の考え方は [../principles.md](../principles.md)、入門はエディタの Learn タブ。

各行の右の「規則」は、その書き方から推敲器（elab）が作る自然演繹の規則。
kernel はこの規則だけを検算する。エディタで証明の行を右クリックし「証明木を見る」を選ぶと、証明の木（Gentzen 式・Fitch 式）として見られる。

## 0. 早見表：goal の形から書き方を選ぶ

証明は「いま示すべきもの（goal）」と仮定の形を見て、1 行ずつ書く。エディタの Goal タブの「次の一手」にも同じ候補が出る。

| goal の形 | 書くもの |
|---|---|
| `∀x. φ` | `Fix x`（条件つき `∀ε>0. φ` なら `Fix ε \| hε : ε > 0`） |
| `φ ⇒ ψ`、`¬φ` | `assume h : φ` |
| `φ ∧ ψ` | `根拠1, 根拠2` |
| `φ ∨ ψ` | `choose left` / `choose right` |
| `∃x. φ` | `choose 項` |
| `=`、`<`、`≤` | `ring`・`linarith`・連鎖 |
| 何でも | `by_contra h`、または根拠 1 つで閉じる |

| 仮定の形 | 使い方 |
|---|---|
| `h : ∃x. φ` | `Obtain x, hx : h` |
| `h : φ ∨ ψ` | `cases h`（下に `Case left h₁`・`Case right h₂`） |
| `h : φ ∧ ψ` | `h.left`・`h.right` |
| `h : ∀x. φ` | `h(t)` |
| `h : φ ⇒ ψ` | `h(p)`（p は φ の根拠） |

途中で示したことを増やす：`k : φ by 根拠`（名前は省略できる）。証明が長ければ `k : φ` の下に字下げして書く。根拠を書かずに `φ` だけ書くとエラーになり、見つかった根拠が直し方として出る（Tab で入る）。

## 1. ファイルの形

```
edition 2026                                   -- ファイルの版（省略すると最新。最初の宣言より前に 1 度だけ）
import analysis.limits                         -- ほかのファイルを読む（§8）
def is_lim(a : ℕ → ℝ, α : ℝ) :⇔ ∀ε>0. …       -- 述語の定義（:⇔。値の定義は :=）
  notation a_n → α (n → ∞)                     -- この定義の記法（§4.1）
const μ : (ℝ → Prop) → ℝ                       -- 定義のない記号（意味は公理で与える）
def sq(x : ℝ) : ℝ := x * x                     -- 項の定義
rec sum(a : ℕ → ℝ, n : ℕ) : ℝ                   -- 原始再帰による定義（§1.1）
  sum(a, 0) = 0
  sum(a, n + 1) = sum(a, n) + a_n
typedef Pos := {x : ℝ | x > 0}                  -- 新しい型（下に空でないことの証明）
axiom triangle : x : ℝ, y : ℝ ⊢ |x + y| ≤ |x| + |y|
@name ja "和の線形性"                           -- 訳名（省略可。次の宣言に付く。docs/language/locale.md）
thm name :                                     -- 定理：見出しは ⊢ を含む行まで
  仮定の並び（x : 型, h : 命題, …）
  ⊢ 結論
証明（字下げで入れ子にする）
```

- コメントは `--`（または `//`）から行末まで。`#` で始まる行は見出し（無視される）。
- 定理の名前には `.` と `_` が使える（`add.zero_left`）。
- 仮定の並びの変数は型を書く。型が決まる場合は省略できる（`x` が `x > 0` から ℝ と決まる、など）。

### 1.1 原始再帰（rec）

`rec f(引数…, n : ℕ, …) : 型` の下に、再帰する引数が `0` のときと `n + 1`（または `S(n)`）のときの 2 つの等式を書く。

- `n + 1` のときの右辺で使える f は、1 つ前の値 `f(…, n, …)` だけ（原始再帰）。0 のときの右辺には f は使えない。
- 再帰しない引数は、見出しと同じ名前のまま書く。値の型は数・命題など（関数の型はまだ使えない）。
- 2 つの等式は定理 `f.zero`・`f.succ` になる（`∀` つき。`sum.succ(a, n)` のように使う）。
- 中身：prelude の再帰定理 `rec.exists`（0 での値と「1 つ前から次を作る規則」から関数がただ 1 つ決まる）と選択 `some` で定義し、2 つの定理の証明も kernel が普通に検算する。新しい推論規則は足していない。
- 例：`lib/algebra/sum.narfi`（Σ と線形性）。`sum(a, n)` は Prose・LaTeX で $\sum_{k<n} a_k$ と書かれる。

| 書き方 | 意味 |
|---|---|
| `ℕ` `ℤ` `ℚ` `ℝ`（`Nat` `Int` `Rat` `Real`） | 数 |
| `Prop` | 命題 |
| `σ → τ`、`σ × τ → ρ` | 関数（`ℕ → ℝ` は数列） |
| `'a` | 型の変数（多相な定理） |
| typedef で作った名前 | 新しい型 |

## 3. 項（数・式）

| 書き方 | 意味 |
|---|---|
| `x`、`ε`（`eps`）、`N_1`（N₁）、`x'` | 変数。ギリシャ文字は英語名で打てる |
| `0`、`12` | 数 |
| `a + b`、`a - b`、`-a`、`a * b`（`·`）、`a / b`、`a^n`、`a²` | 演算。`*` は表示では記号なしで並ぶ |
| `2x`、`2(a + b)`、`3a_n` | 数のあとの積（`2 * x` と同じ）。`ab` は 1 つの名前で、積ではない |
| `|x|`（`abs(x)`）、`max{a, b}`、`min{a, b}` | 絶対値・最大・最小（`max(a, b)` は書かない） |
| `f(x)`、`f(x, y)` | 関数の適用 |
| `a_n`、`a_{n+1}`、`a_1` | `a : ℕ → σ` が宣言されていれば `a(n)`・`a(n+1)`・`a(1)`（数列の添字） |
| `u^n`、`F_i^j`、`F_{i+1}^{j}` | 上付きも、関数に付いたら引数：`u : ℕ → σ` なら `u(n)`、`F : ℕ × ℕ → σ` なら `F(i, j)`（下が先、上が後）。数に付いたら冪（`a_n^2` は `a(n)²`、`x^2` は `x²`） |
| `(x : ℕ ↦ t)`（`|->`、`\mapsto`） | λ（関数そのもの） |
| `{x : ℕ | φ}` | 集合（`ℕ → Prop` の値） |
| `S(n)` | 後者（ペアノ） |

`|-x|` は絶対値（`|-` は ⊢ ではない。ソースでは `| -x|` と空白を挟んで書かれる）。

## 4. 命題

強いものから順に：

| 書き方 | 意味 |
|---|---|
| `t = s`、`≠`、`<`、`≤`（`<=`）、`>`、`≥`（`>=`） | 関係 |
| `x ∈ A`（`in`）、`x ∉ A`、`A ⊆ B`（`subseteq`）、`A ⊂ B`、`A ⊊ B`（`subsetneq`） | 集合（`x ∈ A` は `A(x)`。`⊂` は `⊆` と同じ、`⊊` は真部分集合） |
| `P(x)`、`is_lim(a, α)` | 述語・定義 |
| `¬φ`（`not`） | 否定（`φ ⇒ ⊥` の略） |
| `φ ∧ ψ`（`and`） | かつ |
| `φ ∨ ψ`（`or`） | または |
| `φ ⇒ ψ`（`=>`）、`φ ⇔ ψ`（`<=>`） | ならば（右結合）・同値。`→`（`->`）は関数の型と略記にだけ使い、ならばには使えない |
| `∀x:σ. φ`（`forall`）、`∃x:σ. φ`（`exists`） | 量化。型 `:σ` は決まるなら省略可 |
| `∀ε>0. φ`、`∀n≥N. φ`、`∃δ:ℝ>0. φ` | 範囲付き：`∀x. x > 0 ⇒ φ`、`∃x. x > 0 ∧ φ` の略 |
| `⊥`（`false`） | 矛盾 |

## 4.1 略記（notation）

記法は、定義の下に字下げして書く（v2.13）。型紙の名前は定義の引数の名前。読み込むときに定義の適用に直すので、kernel は記法を知らない。

```
def is_lim(a : ℕ → ℝ, α : ℝ) :⇔ ∀ε>0. ∃N:ℕ. ∀n≥N. |a_n − α| < ε
  notation a_n → α (n → ∞)
```

- 型紙の中の名前のうち、定義の引数（`a`・`α`）は入る所、それ以外（`n`）は束縛変数か、書いたとおりの文字。
- 関数の引数 `a` に、引数でない文字が添字で付いた `a_n`（`a_{n}`）は「n を含む式が入る所」で、`a` には `(n : ℕ ↦ その式)` が渡る。
- すでにある記号（他人の定義）に記法を付けるときは、独立した形も使える。右辺に定義の適用を書く：

```
notation a → α (n → ∞) := is_lim((n : ℕ ↦ a), α)
```

型紙の中の名前は、右辺で決まる：

| 右辺での現れ方 | 型紙の中での意味 |
|---|---|
| 述語の引数（`α`、`a`） | 入る所。式が入る |
| λ の中身（`(n : ℕ ↦ a)` の `a`） | 入る所。束縛変数 n を含んでよい式が入る |
| λ の束縛変数（`n`） | 束縛変数。使うときは、どの文字でもよい（型紙の中の出現はすべて同じ文字） |
| 右辺にない名前・記号（`→`、`∞`、`(`） | 書いたとおりの文字 |

上の宣言のあとでは、次がどれも書ける：

| 書いたもの | 述語の適用 |
|---|---|
| `a_n → α (n → ∞)`、`a_k → α (k → ∞)` | `is_lim(a, α)`（`(n ↦ a_n)` は `a` に縮める） |
| `a_{n+1} → α (n → ∞)` | `is_lim((n ↦ a_{n+1}), α)` |
| `a_n + b_n → α + β (n → ∞)` | `is_lim((n ↦ a_n + b_n), α + β)` |

決まり：

- 右辺は名前の付いた述語（def）の適用。引数は名前か `(n : σ ↦ 名前)`。入る所はそれぞれ型紙にちょうど 1 回、束縛変数は 1 回以上書く。
- 型紙には記号か文字を少なくとも 1 つ書き、入る所・束縛変数のあいだには記号か文字を置く。型紙は束縛変数で始められない。
- あいまいなものは書けない：型紙が、すでにある書き方（ほかの略記を含む）でまるごと読めるとき、ほかの略記と同じ形のときは構文エラー。
- 型紙の最後の入る所には式がまるごと入る（命題になる略記 `a ≺ b` なら、`x ≺ y + 1` の `y + 1`）。途中の入る所は、次の記号の手前まで。
- 同じ述語に略記を複数置ける（表示には最初のものを使う）が、標準ライブラリでは 1 つの概念に 1 つにしている（[notation.md](notation.md)）。
- 新しい記号（`⟶`、`~>` など）は、略記を宣言すると読めるようになる。組み込みの記号（`=>`、`<` など）だけからなる型紙は、普通の式と区別できないので書けない。

**値になる略記**：右辺が値を返す関数（`def f(…) : σ := …`・`rec`）なら、型紙は項として読まれる。

```
def plus(x : ℝ, y : ℝ) : ℝ := x + y
notation x ⊕ y := plus(x, y)            -- a ⊕ b + c は plus(a, b) + c
```

値になる略記の端（最初・最後）の入る所には、1 つのまとまり（名前・数・括弧・関数の適用・添字・冪）だけが入る。`x ⊕ y + z` は `(x ⊕ y) + z`。それより広い式は括弧に入れる。表示でも、必要なら括弧を付ける。

**下に添字の付く演算子**：`\lim`・`\limsup`・`\liminf`・`\max`・`\min`・`\sup`・`\inf`・`\argmax`・`\argmin` は、`\lim_{n → ∞}` のように下に添字を付けて型紙に使える。組み込みの意味はなく、意味は notation で付ける（エディタでは下に入力欄のある形になる）。

```
notation \lim_{n → ∞} a = α := is_lim((n : ℕ ↦ a), α)      -- 命題になる略記
notation \max_{i ≤ m} f := top((i : ℕ ↦ f), m)             -- 値になる略記
```

同じ演算子に別の型紙を置いてよい（`\max A` と `\max_{x ∈ A} f` など）。どれも核の 1 つの形に読み直される。

組み込みの書き方の多くも、同じ考え方の略記である：`|x|` は `abs(x)`、`x ≠ y` は `¬(x = y)`、`¬φ` は `φ ⇒ ⊥`、`2x` は `2 · x`、`∀x>a. φ` は `∀x. x > a ⇒ φ`、`a_n` は `a(n)`（a が数列のとき）。上付きはいつも冪（関数の添字には使わない：`F(i, j)`・`u(n)` と書く）。

## 5. 証明の文

字下げした下の行は、その文の中（新しく入った変数・仮定が使える範囲）。

| 書き方 | 意味 | 規則 |
|---|---|---|
| `Fix x` / `Fix x, y` | goal `∀x. φ` の x を任意にとる | ∀I |
| `Fix ε \| hε : ε > 0` | `∀ε. ε > 0 ⇒ φ` の ε と仮定を一度に | ∀I・⇒I |
| `assume h : φ` | goal `φ ⇒ ψ` の φ を仮定する。中身 `: φ` は省略できない | ⇒I |
| `by_contra h` | goal φ の否定 `h : ¬φ` を仮定して ⊥ を示す | RAA（古典論理） |
| `Obtain x, hx : e` | `e : ∃x. φ` から x と `hx : φ(x)` を取り出す | ∃E |
| `Obtain N(ε), hN : e` | 同じ。N が ε にだけ依ることを確かめる | ∃E |
| `choose t` / `choose t, j` | goal `∃x. φ` の x として t をとる（範囲の条件は j で） | ∃I |
| `choose left` / `choose right` | goal `φ ∨ ψ` のどちらを示すか | ∨I₁ / ∨I₂ |
| `cases h` の下に `Case left h₁` / `Case right h₂` | `h : φ ∨ ψ` で場合分け | ∨E |
| `induction n` の下に `Case zero` / `Case succ k, IH : φ(k)` | 数学的帰納法。IH の中身は省略できない | Ind |
| `let N := t` | 名前を付ける | （定義の展開） |
| `j` | 根拠 j で goal を閉じる | （j による） |
| `h : φ by j`（`φ by j`） | **事実の行**：φ を j で示す。最後の行なら φ は goal と同じでなければならない（goal を閉じる）。後ろに行が続けば h（名前がなければ this）として使える | （j による。木では使った所に差し込む） |
| `h : φ` の下に字下げして証明 | 同じ。φ の証明をブロックで書く | 同上 |
| `φ`（根拠なし） | エラー。検査器が根拠を探し、見つかったものを直し方として示す（勝手には補わない） | なし |
| 連鎖（下） | 等式・不等式の変形。`by` を書かない段はエラーになり、探した根拠の候補が直し方として出る | 推移律 |
| `∴ φ`（`therefore`） | 直前の行（またはブロック）で示したことが φ であることを確かめる。ブロックの先頭など、まだ何も示していない所では書けない。エディタは、2 行以上のブロックの終わりに「∴ そのブロックで示したこと」を薄く表示する（ファイルには入らない） | なし |

v2.13 で消した書き方：`have h : φ := j`（→ `h : φ by j`）、`contradiction h k`（→ `k(h)`）、`unfold …`（書かなくてよい）、`suffices ψ := j`（→ ψ を示してから閉じる）。

連鎖：

```
|a + b|
  ≤ |a| + |b|     by triangle(a, b)
  < ε/2 + ε/2     by h₁, h₂
  = ε             by ring
```

## 6. 根拠（`by` の右・`:=` の右・閉じる行）

| 書き方 | 意味 | 規則 |
|---|---|---|
| `h` | 文脈の仮定 | 仮定 |
| `thm_name` | 定理・公理（変数は単一化で決まる） | 定理の具体化 |
| `h(t)`、`h(t, p)` | ∀ に項 t を入れ、⇒ に証拠 p を渡す（順に）。`h(t)(p)` と分けても同じ | ∀E・⇒E |
| `p, q` | ∧ の両側 | ∧I |
| `h.left`、`h.right` | ∧ の左・右 | ∧E₁・∧E₂ |
| `refl` | `t = t` | 反射律 |
| `ring` | 環の等式（多項式として等しい） | 証明書を kernel が検算 |
| `linarith` | 文脈の一次不等式から（goal が `⊥` なら、仮定の不等式の矛盾から） | 証明書（Farkas）を kernel が検算 |
| `decide` | 変数のない命題を計算 | kernel が計算 |
| `sorry` | 未完成（定理は incomplete になる） | なし |
| `EQ2(eq, p)` | 等号による書き換え | =E |
| `name.def` | 定義の同値（`P(x) ⇔ 本体`） | δ |

規則の名前でも書ける（短い書き方と同じ証明になる）：

| 規則の名前 | 短い書き方 | 規則 |
|---|---|---|
| `and.intro(p, q)` | `p, q` | ∧I |
| `and.left(h)`、`and.right(h)` | `h.left`、`h.right` | ∧E₁、∧E₂ |
| `or.left(p)`、`or.right(p)` | `choose left` の下で `p` | ∨I₁、∨I₂ |
| `imp.elim(f, a)` | `f(a)` | →E |
| `all.elim(h, t)` | `h(t)` | ∀E |
| `bot.elim(h)` | （`h : ⊥` なら `h` だけで） | ⊥E |

導入の規則のうち、仮定を打ち消すもの（→I・∀I・∃E・∨E・RAA・Ind）は、文（§5）で書く。

## 7. 自然言語での読み（日本語・英語）

言語の核は §1〜6 の ASCII の書き方だけ。日本語・英語での読みはロケールの表が決める（[locale.md](locale.md)）。
エディタの `JA`／`EN` は表示を変えるだけで、ファイルは変わらない。読みで書いた行も読める。日本語の例：

| 日本語 | 標準 |
|---|---|
| `hε : ε > 0 を満たす ε を任意にとって固定する` | `Fix ε \| hε : ε > 0` |
| `h : P と仮定する` | `assume h : P` |
| `背理法により h と仮定する` | `by_contra h` |
| `j より N(ε), hN が存在する` | `Obtain N(ε), hN : j` |
| `t をとればよい` | `choose t` |
| `j より h : φ が成り立つ` | `h : φ by j` |
| `h : φ を示す`（下に証明） | `h : φ`（下に証明） |

## 8. import の探し方

`import a.b` は `a/b.narfi` を、(1) 書いたファイルと同じフォルダ、(2) `NARFI_PATH`、(3) `~/.narfi/lib`（Web 版は保存領域の `lib/`）、(4) 標準ライブラリ の順に探す。
