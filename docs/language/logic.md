# Narfi 言語仕様 v2.6 — 核の論理

この文書は **kernel が何を検査するか** を定める。表層の構文（`Fix`・`Obtain`・連鎖など）は
elab が kernel の証明項に翻訳する（§10）。kernel の外のコードは、この仕様の正しさに関与しない。

v2.0 は多ソート一階述語論理、v2.1 で **単純型理論（HOL）** に広げた。v2.2 で型の定義（typedef）と商、
v2.5 で値が関数の定義・原始再帰（rec）を足した。表層の書き方は [syntax.md](syntax.md)。

---

## 1. 型

```
σ ::= ℕ | ℤ | ℚ | ℝ          数の型
    | T                        typedef で作った型（§8.3）
    | Prop                     命題の型
    | σ₁ × … × σₙ → τ         関数型（τ が Prop なら述語・集合）
    | 'a | 'b | …             型変数（定理の図式の中だけに現れる。§8）
```

関数の値の型 τ には関数型も書けるが、項の定義（§8.2）の値には関数型・Prop は使えない。
`×` は関数の引数の並びにだけ現れる（ℕ × ℕ という型の値はない）。

## 2. 組み込みの記号

| 記号 | 型 | 使える型 |
|---|---|---|
| 数字 `0, 1, 2, …` | σ | ℕ ℤ ℚ ℝ（文脈から決まる。§3.2） |
| `S` | ℕ → ℕ | ℕ |
| `+`, `·` | σ × σ → σ | ℕ ℤ ℚ ℝ |
| `-`, `neg`（単項の −）, `abs` | σ × σ → σ / σ → σ | ℤ ℚ ℝ |
| `/` | σ × σ → σ | ℚ ℝ |
| `max`, `min` | σ × σ → σ | ℕ ℤ ℚ ℝ |
| `^` | σ × ℕ → σ | ℕ ℤ ℚ ℝ |
| `some` | (σ → Prop) → σ | すべての型（選択。§8） |
| `=` | σ × σ | すべての型（関数型・Prop も） |
| `<`, `≤`, `>`, `≥` | σ × σ | ℕ ℤ ℚ ℝ |

`a ≠ b` は `¬(a = b)` の略記、`¬φ` は `φ → ⊥` の略記。

## 3. 項・論理式と型付け

```
t ::= x | n（数字） | f(t₁, …, tₙ)            f は組み込み・項の定義・関数型の変数・typedef の定数
    | t(t₁, …, tₙ)                            一般の適用（t は関数を値とする項。内部では @(t, t₁, …)）
    | (x₁:σ₁, …, xₙ:σₙ ↦ t)                  λ 抽象（関数そのもの）
    | {(x₁:σ₁, …, xₙ:σₙ) | φ}                集合（述語そのもの）
φ ::= P(t₁, …, tₙ) | t(t₁, …, tₙ) | t₁ R t₂ | ⊥ | φ → ψ | φ ∧ ψ | φ ∨ ψ | ∀x:σ. φ | ∃x:σ. φ
                                             P は述語の定義・述語型（または Prop 型）の変数、
                                             t は述語を値とする項（集合を返す関数の値など）
```

表層の `t ∈ A` は `A(t)`（A が集合なら β 簡約したもの）、`A ⊆ B` は `∀x. x ∈ A → x ∈ B` の略記。

### 3.1 型付け規則（kernel が検査する）

- 変数 `x` の型は文脈で宣言された σ。
- `f(t₁,…,tₙ)` は、`f : σ₁ × … × σₙ → τ`（τ ≠ Prop）で各 `tᵢ : σᵢ` のとき `τ`。
- 一般の適用 `t(s₁,…,sₙ)` は、`t : σ₁ × … × σₙ → τ`（τ ≠ Prop）で各 `sᵢ : σᵢ` のとき `τ`。
  論理式の位置の `t(s…)` は τ = Prop のとき。
- `(x₁:σ₁, … ↦ t)` は、`x` を文脈に足して `t : τ` のとき `σ₁ × … → τ`。
- `{(x₁:σ₁, …) | φ}` は、`x` を文脈に足して φ が論理式のとき `σ₁ × … → Prop`。
- `P(t₁,…,tₙ)` は、`P : σ₁ × … × σₙ → Prop`（n = 0 なら `P : Prop`）で各 `tᵢ : σᵢ` のとき論理式。
- `t₁ R t₂` は両辺が同じ型で、`R` がその型で使えるときに論理式。
- 束縛変数（∀・∃・λ・集合）の型は必ず書かれている（elab が推論して埋める。kernel は推論しない）。

### 3.1.1 適用の形

項・論理式の中で、λ や集合を直接適用した形（`(x ↦ t)(s)`）は持たない。関数型・述語型の変数に
λ・集合を **代入した瞬間に β 簡約する**（遺伝的代入、`src/syntax.rs` の `subst`）。
一般の適用 `@(t, s…)` も、代入で t が λ・集合・名前になった瞬間に、普通の適用・β 簡約に戻す。
代入する前に型を検査するので、β 簡約は必ず止まる（単純型付き λ 計算の正規化性）。

### 3.2 数字の型

数字だけからなる項（`2 + 2`、`1/2` など）は、周りから型が決まらないことがある。
このときは、使われている演算が意味を持つ **最小の** 数のソートで読む
（`+ ·` だけなら ℕ、`-` があれば ℤ、`/` があれば ℚ）。
ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ の埋め込みは `+ · - / < =` を保つので、どのソートで読んでも真偽は変わらない。

### 3.3 型の推論（elab の仕事。kernel は信じない）

elab は単一化で型を決める。決まらないときの扱い：

- 数字だけの部分 → §3.2 の規則。
- 変数で、数の演算に使われているのに ℕ/ℤ/ℚ/ℝ のどれか決まらない → **エラー**（`x : ℝ` と書かせる）。
- 何の制約もない変数（`∀x. x = x` の x など） → 定理ならソート変数 `'a` にする（§7）。

## 4. 判断と文脈

```
Γ ::= · | Γ, x : σ | Γ, x : σ := t | Γ, h : φ
Γ ⊢ p : φ      「文脈 Γ で、証明項 p は φ を示す」
```

`x : σ := t` は局所的な定義（`let`）。仮定の名前 `h` は重ねてよい（後のものが見える）が、
変数の名前は重ねてはならない。

## 5. 推論規則（kernel の証明項）

`φ ≡ ψ` は §6 の定義的等しさ。規則の前提で「φ が ∀ の形」などと言うときは、
先頭の定義を展開してから形を見る（§6 の whnf）。

| 証明項 | 前提 | 結論 | 条件 |
|---|---|---|---|
| `Hyp(h)` | `h : φ ∈ Γ` | φ | |
| `ImpI(h, φ, p)` | `Γ, h:φ ⊢ p : ψ` | φ → ψ | |
| `ImpE(p, q)` | `p : φ → ψ`, `q : φ'` | ψ | φ ≡ φ' |
| `AndI(p, q)` | `p : φ`, `q : ψ` | φ ∧ ψ | |
| `AndE(左/右, p)` | `p : φ ∧ ψ` | φ / ψ | |
| `OrI(左/右, ψ, p)` | `p : φ` | φ ∨ ψ / ψ ∨ φ | |
| `OrE(p, h₁.q₁, h₂.q₂)` | `p : φ ∨ ψ`, `Γ,h₁:φ ⊢ q₁ : χ`, `Γ,h₂:ψ ⊢ q₂ : χ'` | χ | χ ≡ χ' |
| `AllI(x, σ, p)` | `Γ, x:σ ⊢ p : φ` | ∀x:σ. φ | x は Γ に現れない（固有変数条件） |
| `AllE(p, t)` | `p : ∀x:σ. φ`, `t : σ` | φ[x := t] | |
| `ExI(∃x:σ.φ, t, p)` | `t : σ`, `p : φ'` | ∃x:σ. φ | φ' ≡ φ[x := t] |
| `ExE(p, x, h, q)` | `p : ∃y:σ. φ`, `Γ, x:σ, h:φ[y:=x] ⊢ q : χ` | χ | x は Γ・χ に現れない |
| `BotE(φ, p)` | `p : ⊥` | φ | |
| `Raa(h, φ, p)` | `Γ, h:¬φ ⊢ p : ⊥` | φ | 古典論理 |
| `Cut(h, φ, p, q)` | `p : φ'`, `Γ, h:φ ⊢ q : χ` | χ | φ ≡ φ'（`have`） |
| `Let(x, σ, t, q)` | `t : σ`, `Γ, x:σ:=t ⊢ q : χ` | χ[x := t] | |
| `Refl(t)` | `t : σ` | t = t | |
| `Subst(p, z, φ, q)` | `p : s = t`, `q : φ'` | φ[z := t] | φ' ≡ φ[z := s] |
| `Ind(x, φ, p₀, k, ih, p₁)` | `p₀ : φ'₀`, `Γ, k:ℕ, ih:φ[x:=k] ⊢ p₁ : φ'₁` | ∀x:ℕ. φ | φ'₀ ≡ φ[x:=0], φ'₁ ≡ φ[x:=S(k)] |
| `Trans(p, q)` | `p : a R b`, `q : b' R' c` | a R'' c | b ≡ b'、R・R' の向きが合う（§5.1） |
| `Antisymm(p, q)` | `p : a ≤ b`, `q : b ≤ a` | a = b | 数のソート |
| `NatNonneg(t)` | `t : ℕ` | t ≥ 0 | |
| `Ring(l, r)` | | l = r | §7.1 |
| `LinArith(φ, ps, cs, c)` | `pᵢ : 不等式` | φ | §7.2 |
| `Decide(φ)` | | φ | §7.3 |
| `Thm(名前, σs, ts)` | | 定理の図式の具体化 | §8 |
| `Sorry(φ)` | | φ | **未完成**として記録される |
| `Line(n, p)` | `p : φ` | φ | 論理的な意味はない（エラーの行番号を示す印） |

### 5.1 推移律の向き

`=` はどちらとも組める。`<`・`≤` 同士は `<` か `≤`（どちらかが `<` なら `<`）。
`>`・`≥` 同士も同様。`<` と `>` のように向きが逆のものは組めない。

## 6. 定義的等しさ

kernel は次の書き換えで同じになる論理式を同じとみなす。

- **α**：束縛変数の名前の違い（`∀x. P(x)` ≡ `∀y. P(y)`、`(x ↦ x)` ≡ `(y ↦ y)`）
- **β**：λ・集合の適用（`(x ↦ t)(s)` ≡ `t[x := s]`）。代入のたびに済ませる（§3.1.1）ので、
  kernel が比べる式はいつも β 正規形。値が関数の定義を展開して λ になったものを、さらに適用したもの
  （`mmul(A, B, n)(i, j)`）も、展開のときに β する（v2.5.10）。
- **δ**：`def` の展開（`is_lim(a, α)` ≡ その本体、`sq(x)` ≡ `x · x`）。定義は再帰しないので展開は必ず止まる。
- **ζ**：`let` の展開（`x := t` のもとで `x` ≡ `t`）

**whnf**（弱頭部正規形）：先頭が定義された述語である限り展開したもの。

η（`(x ↦ f(x))` ≡ `f`）は定義的等しさに **入れていない**。必要なら外延性の公理（§8）で示す。

## 7. 算術

数のソートは次の構造を持つと **仮定する**（これが算術の公理系である）：
ℕ は可換順序半環、ℤ は可換順序環、ℚ・ℝ は順序体。ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ は埋め込みで、
`S(n) = n + 1`、数字 `n` は `S(…S(0))` と同じ値。

kernel はこの公理から直接出る事実だけを、計算で確かめる。

### 7.1 `Ring(l, r)`：環の等式

`l - r` を多項式に正規化し、0 になれば `l = r`。正規化では：

- `S(x)` は `x + 1`、`^` は指数が数字のときだけ展開、`x / c`（c は 0 でない数字）は `x · (1/c)`。
- それ以外（`abs(t)`・`max(s,t)`・`x/y`・局所記号 `a(n)` など）は **原子**（ひとつの変数）として扱う。
  原子の引数は正規化してから比べる（`abs((a+b)-c)` と `abs(a-c+b)` は同じ原子）。

これは「関数は等しい引数に等しい値を返す」（合同性）と環の公理だけを使う。
`x/0` の値は決めていないが、原子として扱うので値を決める必要がない。

### 7.2 `LinArith(φ, ps, cs, c)`：線形算術の証明書（Farkas の補題）

各 `pᵢ` の結論を `eᵢ ⋈ᵢ 0`（⋈ ∈ {>, ≥, =}）に直す（`a < b` は `b - a > 0` など）。
目標 φ の否定も同じ形 `e ⋈ 0` に直す。証明書は係数 `cᵢ`（と否定に掛ける `c`）。

kernel は `Σ cᵢ·eᵢ + c·e` を §7.1 で正規化し、定数 `k` になることを確かめる。
`⋈` が `>`・`≥` の項の係数は 0 以上でなければならない（`=` は符号自由）。そのうえで
**k < 0、または k = 0 で係数が正の `>` がある** なら矛盾なので、φ が成り立つ。
すべての項は同じ数のソート（ℕ のときは ℤ に埋め込んで計算する）でなければならない。

### 7.2.1 桁あふれ

有理数は 128 ビット整数の分数で計算する。桁あふれを検出したら検査を止める（誤って通さない）。

### 7.3 `Decide(φ)`

変数・局所記号を含まない φ を有理数で計算して真なら φ。`abs`・`max`・`min` は通常の意味で計算する。
0 での割り算を含むときは計算しない（拒否）。

## 8. 理論：公理・定理・定義

### 8.1 公理と定理

- **公理**（`axiom`）は図式として環境に入る。kernel は、どの定理がどの公理に依存したかを記録する。
  prelude の公理は **核の公理**、それ以外は **利用者の公理** として区別して報告する。
- 核の公理（`src/prelude.narfi`）：
  - 等号：`EQ1`（反射律。書き換えは規則 `Subst`）
  - ペアノ：`PA1`・`PA2`、加法・乗法の定義（帰納法は規則 `Ind`）
  - 外延性：`funext`（関数）・`propext`（命題）・`setext`（集合）
  - 選択：`choice : (∃x. P(x)) → P(some(P))`（Hilbert の ε）
  - 再帰定理：`rec.exists : ∃F. F(0) = c ∧ ∀k. F(S(k)) = g(k, F(k))`（v2.5.9。HOL と帰納法から証明できる定理だが、
    いまは公理として置く。`rec` の定義はこれと選択で作る）
- **定理** は kernel が証明を検算したあと図式として環境に入る。図式の **パラメータ** は
  1. 型変数 `'a, …`
  2. 文の自由変数（型つき）。関数型・述語型・命題型の変数も含み、λ・集合・論理式を代入できる
     （二階の図式の具体化）。
- `Thm(名前, σs, ts)` の結論は、図式の仮定 `h₁ … hₖ` と結論 φ を `h₁ → … → hₖ → φ` にし、
  型変数に σs、パラメータに ts を代入したもの（ts は型を検査してから代入する）。

### 8.2 定義

- **述語の定義** `def P(x₁:σ₁, …) := φ`、**項の定義** `def f(x₁:σ₁, …) : τ := t`。
- 本体の自由変数は引数だけ。本体に現れる記号は定義済みのものだけ（自分自身は使えない）。
- 定義は **保存的拡大**（定義を足しても、定義を使わない命題の証明可能性は変わらない）。
- 型変数を持つ定義はまだ書けない（引数の型が決まらないときはエラー）。
- 項の定義の値は、数・型の定義で作った型・**関数**（`ℕ × ℕ → ℝ` など。v2.5.10）。命題を値にするなら述語の定義を使う。
- **原始再帰** `rec f(…, n : ℕ, …) : τ`（0 と n + 1 の 2 つの等式）は、`some({F | F(0) = c ∧ ∀k. F(S(k)) = g(k, F(k))})(n)`
  という項の定義と、2 つの等式の定理（証明は rec.exists と choice から作られ、kernel が普通に検算する）に展開される。

### 8.3 型の定義（typedef）

```
typedef T := {x : σ | φ}
  （∃x:σ. φ の証明）
```

φ の自由変数は x だけでなければならない。証明 p が `∃x:σ. φ` を示すとき（kernel が検算する）、
次を環境に加える（`src/kernel/mod.rs` の `add_typedef`）。

- 新しい基本型 `T`
- 定数 `T.abs : σ → T`、`T.rep : T → σ`
- 公理（核の公理として扱い、p が依存したものを引き継ぐ）
  - `T.rep_prop : ∀t:T. φ[x := T.rep(t)]`（rep は集合に入る）
  - `T.abs_rep : ∀t:T. T.abs(T.rep(t)) = t`
  - `T.rep_abs : ∀x:σ. φ → T.rep(T.abs(x)) = x`

これは HOL Light・Isabelle/HOL の型定義の規則と同じで、**保存的拡大** である
（T を {x : σ | φ} そのものと読むモデルが作れる。ただし集合が空でないことが必要で、それを証明 p が保証する）。

**空でないことが本質的である**：HOL ではどの型も空でない（`some` で必ず元が作れる）ので、
空の集合で typedef すると `rep_prop` から矛盾が出る。証明を `sorry` で済ませた typedef は
未完成として扱われ、それに依存する定理もすべて未完成になる（`tests/unsound_typedef.narfi`）。

### 8.4 商

商は新しい規則を足さずに、typedef と集合で作る。同値関係 `~` を持つ型 σ について、

```
typedef Q := {c : σ → Prop | ∃a:σ. c = {b : σ | a ~ b}}     -- 同値類全体
def cls(a : σ) : Q := Q.abs({b : σ | a ~ b})               -- a の同値類
```

`~` が同値関係なら、次の3つが証明できる（`lib/reals/real.narfi` で ℝ について示した）。

- sound：`a ~ b → cls(a) = cls(b)`（集合の外延性 `setext` を使う）
- exact：`cls(a) = cls(b) → a ~ b`（`rep_abs` で同値類を取り出す）
- surjective：`∀q:Q. ∃a:σ. q = cls(a)`（`rep_prop` と `abs_rep`）

## 8.5 kernel が保証すること・しないこと

kernel が保証するのは「**kernel が受け取った文**（型のついた論理式）が、上の規則・公理から導ける」ことまで。
ソースの文を parser が正しく読んだか、`notation` が紛らわしくないかは、人が文の表示を見て確かめる。
kernel のほかに、`src/syntax.rs` の代入・自由変数の計算（`subst`・`subst_many`・`free_vars`・
`instantiate`・`map_sorts`・`canonical`）と `src/types.rs` の型の読み書きも信頼の土台に入る。

## 9. まだ含めないもの

- 型変数を持つ定義（`def subset(A : 'a → Prop, …)` のような多相な定義）
- 命題を値とする項の定義（述語の定義を使う）
- 積の型（`ℕ × ℕ` の値）。2変数の集合は `{(x, y) : ℕ × ℕ | φ}` で書ける

## 10. 表層の構文と証明項の対応

| 表層（[syntax.md](syntax.md)） | 証明項 |
|---|---|
| `Fix x` / `Fix x \| h : φ` | `AllI(x, σ, …)` / `AllI(x, σ, ImpI(h, φ, …))` |
| `assume h : φ` | `ImpI(h, φ, …)` |
| `by_contra h` | `Raa(h, φ, …)` |
| `Obtain x, h₁, h₂ : e` | `ExE(e, x, h, Cut(h₁, …, AndE(…), Cut(h₂, …)))` |
| `cases h`（`Case left h₁` / `Case right h₂`） | `OrE` |
| `induction n`（`Case zero` / `Case succ k, IH : φ`） | `Ind`（文脈の変数なら `AllE(Ind(…), n)`） |
| `h : φ by j`（後ろに行が続く） | `Cut(h, φ, j, …)`（名前がなければ h = this） |
| `φ by j`・`j`（goal を閉じる） | j の証明項 |
| `choose t` / `choose t, j` | `ExI` / `ExI(…, AndI(j, …))` |
| `choose left` / `right` | `OrI` |
| `let x := t` | `Let` |
| 連鎖 `a = b by … < c by …` | `Trans`（足りないときは `LinArith`） |
| `∴ φ` | なし（elab が確かめるだけ） |

根拠：

| 根拠 | 証明項 |
|---|---|
| 仮定 `h` | `Hyp(h)` |
| 定理・公理の適用 `t(a, b)` | `Thm` に `AllE`・`ImpE` を重ねる |
| `p, q`（`and.intro(p, q)`） | `AndI` |
| `h.left` / `h.right`（`and.left(h)` / `and.right(h)`） | `AndE` |
| `or.left(p)` / `or.right(p)` | `OrI` |
| `imp.elim(f, a)`・`all.elim(h, t)` | `ImpE`・`AllE` |
| `bot.elim(h)`、goal と違う ⊥ の根拠 | `BotE` |
| `refl` / `ring` / `linarith` / `decide` / `sorry` | `Refl` / `Ring` / `LinArith` / `Decide` / `Sorry` |
| `EQ2(h, hφ)` | `Subst`（elab が φ を見つける） |

仮定を導入する文（`Fix x | h : φ`・`assume h : φ`・`Case succ k, IH : φ`）では、仮定の中身 φ を省略できない（v2.5）。
φ は goal から一意に決まるので kernel にとっては不要だが、証明を読む人に仮定が見えるようにするため、elab が要求する。
同じ理由で、事実の行の根拠も省略できない（v2.6）。省略するとエラーになり、elab が探した根拠を直し方として示す
（設計原則 2：勝手に補わない）。
