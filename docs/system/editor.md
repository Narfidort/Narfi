# エディタ（v2.8）

`narfi/src/web_ui.html`（1 ファイル）。ローカル版（`narfi web`）と Web 版で同じものを使う。

## 文書の持ち方
- 各行を構造化された木（`Seq` の中に文字・記号・分数・添字・絶対値・Σ などのノード）として持ち、その上でカーソルを動かす（Mathcha 風）。
- 保存するのは ASCII の文字列（`serializeDocToAscii`）。読み込みは `parseAsciiToItems`。往復で証明の意味が変わらないことをテストで確かめている（[testing.md](testing.md)）。
- 元に戻す・やり直すは木をそのまま複製して持つ。

## 表示の層（ファイルを変えない）
- 日本語シュガー（`JP`）：行を日本語の証明文の形で見せる。
- 添字・積・行列・Σ の見え方、宣言名の立体。
- ブロックの終わりの「∴ そのブロックで示したこと」（薄い表示）。

## 検査とのやりとり
- 編集が止まると `/api/check` に送る（Web 版は WebAssembly）。返ってくるのは、宣言ごとの結果・エラー（直し方 `fix`・候補 `alts`）・警告（書き換え先 `replace`）・各行の文脈と goal と次の一手（`steps[].hints`）・Prose・LaTeX・証明木。
- 直し方：行末の薄い文字（Tab で入る）、Goal タブの「次の一手」「根拠の候補」のボタン。原則 2（勝手に補わない）により、入れるのは必ず利用者の操作。

## Learn（チュートリアルとコース）
- 中身は `src/tutorial.js`（レッスン 1〜16 と早見表）と `src/course.js`（コース 0〜5）。どちらも `scripts/learn/` の Python で作る（`python3 scripts/learn/tutorial.py`。コースの練習と答えは `scripts/learn/course/`）。各レッスンは、紙の証明・Narfi のコード・1 行ずつの説明・打ち方・つまずき・練習（課題・段階的なヒント・答え）。
- 「練習のファイルを開く」で、自分のファイルに `learn/番号-名前.narfi`（コースは `course/番号-名前.narfi`）を作って開く。番号はレッスン・章の番号。すでにあれば続きから開く。全部検証できると、そのレッスンに ✓ が付く。
- 例と答えが通り、練習が未完成（△）になることを `tests/ui.rs`（tutorial_answers_check）で確かめる。

## 検索・置換・整形
- **⌘F**（Ctrl+F）で検索、**⌘⌥F**・⌘H で置換の欄も開く。探すのはソースの文字列（ファイルに保存される形）で、行ごと。打った記号（`ℝ`・`⇒` など）はソースの書き方（`Real`・`=>`）に直して探す。
  - `Aa`：大文字と小文字を区別、`.*`：正規表現（置換で `$1` が使える）。Enter で次、⇧Enter で前、Esc で閉じる。置換の欄で Enter は 1 つ置換、⌘Enter はすべて置換。
  - 一致した行は行番号に印が付き、今の一致は選択される。
- **⇧⌥F**（File → Format Document）で整形：行末の空白を消す、続く空白を 1 つにする、`,` の後に空白、連鎖の `by` の列をそろえる、空行を 2 つ以上続けない。空白だけを変えるので証明の意味は変わらない（`narfi fmt [--write]` も同じ。`src/format.rs`）。

## 描き直し
- 行ごとに、見た目に効くもの（中身・字下げ・カーソル・選択・印・Markdown・読み・∴・名前の一覧・行の木の番号）を key にして、描いた結果と比べる。key が変わった行だけを描き直し、DOM もその行だけ入れ替える（`renderEditor`）。行が増減したときは、後ろの行は行番号だけ付け直す。
- 検査の結果が届く前に編集したときは、検査した本文と今の本文を比べて、印・∴ の行番号をずらしてから当てはめる。
- 検索の一致の印は、行を描き直さずにクラスだけ付け替える。
- 行がコメントかどうかは、描くあいだ行ごとに覚えておく（文字ごとに全行を探さない）。

## 印刷
- File → Print (Prose)（⌘P）：Prose を A4 に（余白 12〜13mm）。はみ出す数式は縮める。
- File → Print (Sugar)（⇧⌥P）：エディタの読みの表示（Sugar）のまま印刷する。言語は Preferences の言語。行番号・カーソルは出さない。
- File → Export PDF (LaTeX)（ローカル版）：余白 15mm。

## 行列の入力
- `[[` と打つか、`\matrix`（`\pmatrix`）で 2×2、`\mat3` で 3×3 の行列の入力欄ができる。成分は Tab・→ で次へ、↑↓ で上下の行へ。
- 成分の中で **Enter** を押すと下に行を、**`&`** を打つと右に列を足す（LaTeX の pmatrix と同じ）。
- 成分の先頭の Backspace：その行（列）が全部空なら行（列）を消す。全部空なら行列を消す。それ以外は前の成分へ。
- ファイルには `[[a, b], [c, d]]` と保存する。

## 記法の補完（文脈の式）
検査器は各行について、goal と仮定に現れる式（`steps[].terms`。述語の定義を 3 段まで展開した形からも集める。数列の適用は `a_n`・`a_{n+1}` の形）と、数列の変数（`steps[].seqs`）を返す。エディタはそこから候補を出す。候補を出すだけで、Tab・Enter で選ぶまで入らない。

| 打つもの | 出る候補 |
|---|---|
| `\|`（項の始まり。直後が空白なら出さない：`Fix ε \| hε`） | 文脈の絶対値 `\|a_n − α\|` など。続けて打つと絞る。`\abs` の中でも出る |
| `(n \|->`（`(n ↦`） | 数列 `(n : ℕ ↦ a_n + b_n)` など（文脈の λ と、数列の変数から作る和・差・積・ずらし）。閉じ括弧ごと入る |
| `\sum` | 文脈の和と `sum(a, n)`（Σ_{k<n} a_k）。Σ の入力欄は `Σ_{k<n} 中身` で、走る添字は文脈で使っていない文字 |
| `Ctrl+Space`・`⌥Space` | 文脈の式すべて（打ちかけの語で絞る） |

Σ の入力欄は `sum((k : Nat |-> 中身), n)` と保存し、読み込むときも同じ形を Σ に戻す（`Σ_{k=0}^{m}` は `sum(…, m + 1)`）。見出しを書いている途中で検査が通らないときは、宣言の行の `a : ℕ → ℝ`・`n : ℕ` から候補を作る。

## AI（任意）
- 設定は Preferences（接続先・モデル・API キー。形式は OpenAI と同じ chat/completions）。既定は OpenCode Go の `glm-5.3-flash`（`scripts/ai_bench.py` で、費用・速さ・正しさを比べて選んだ）。
- 右の AI タブ：「次の一手」（カーソルの位置に `sorry` を置いて検査し、そこの文脈と goal を渡す）・「sorry を埋める」・「エラーの説明」・質問。
- 「次の一手」「sorry を埋める」は、答えを検査器にかけ、通らなければエラーを返して直させる（最大 3 回・120 秒）。通った案だけに「入れる」ボタンを出す（原則 1・2）。途中までの案は、続きに `sorry` を置いた形で確かめる。入れたあとも「元に戻す」で戻せる。

## 数式の入力欄
エディタの入力欄（分数・添字・上付き・根号・絶対値・Σ・下に添字の付く演算子など）は、見た目を作るだけで意味を持たない。保存すると言語の文字列になり、意味は言語（組み込みの略記と notation）が決める（docs/language/syntax.md §3・§4.1）。
- 下に添字の付く演算子：`\lim`・`\limsup`・`\liminf`・`\max`・`\min`・`\sup`・`\inf`・`\argmax`・`\argmin`。打つと下に入力欄ができ、`\lim_{n -> infty}` と保存される。下が空なら `\max ` と保存される。
- 上付きの入力欄は `^` で作る（`\superscript` でも。`\sup` は上限の演算子）。


## 数式の描画（KaTeX）

行の中の数式は、組版（間隔・上下限の位置・記号の大きさ・添字）を LaTeX と同じにするため、KaTeX で描く。`?kx=0` で従来の自前の描画（HTML と CSS）に戻せる（選んだ値は localStorage `narfi.kx` に残る）。

- 行の中の「数式の連なり」（キーワード `thm`・`by`・`Fix` など、数式にしない語で区切られた範囲。前後の空白は含めない）を 1 つの LaTeX にして描く（`kxRunHtml`・`kxItems`）。文字・記号・分数・∑∫∏・√・絶対値・括弧・二項係数・行列・アクセント・`\lim`・上付き・下付きを含む。キーワードは従来どおり HTML で描く。
- 各項目と入力欄に `\htmlData` で `data-seq`・`data-idx`・`data-slot-seq` を付けるので、クリックの対応づけ（`hitTestPos`）は従来と同じ属性で動く。
- カーソルと選択は、描いたあとの要素の位置を測って重ねる（`kxOverlay`）。連なりの端（最初の項目の前・最後の項目の後）のカーソルは、従来どおり行の流れの中に置く。木の操作（矢印キー・入力・削除）は DOM に頼らないので変わらない。
- 行の中は通常のインライン配置（`.kxflow`）にして、数式の基準線を文字にそろえる。
- 局所描画（変わった行だけ描き直す `domKeys` の仕組み）はそのまま。KaTeX の出力は LaTeX 文字列ごとにメモ化し、カーソルや選択は含めない。
- KaTeX で描けないとき（未対応の文字など）は、その連なりだけ従来の描画にする。
- 確認：`node tests/render_check.js`（従来と KaTeX 版の両方で、はみ出しを測って写真を残す）。

## 範囲を選んだまま記号を打つ

1 行の中で範囲を選んで次の記号を打つと、置き換えずに選んだものを使う（`wrapSelection`。1 回の取り消しで戻る）。

| 打つ記号 | 結果 |
|---|---|
| `(` `[` `{` `"` | 選んだものを囲む |
| `<` | ⟨ ⟩ で囲む |
| `\|` | 絶対値の中に入れる |
| `/` | 選んだものを分子にした分数（カーソルは分母へ） |
| `^` `_` | 選んだものを底にして上付き・下付き（2 つ以上の項なら括弧で囲んでから） |
| `\` から記号を補完 | 選んだものが、その記号の作用域になる：`\int`・`\sum`・`\prod` は中身（カーソルは下限へ）、`\frac`・`\binom` は上（カーソルは下へ）、`\sqrt`・`\abs`・`\norm`・`\vec` などは中身、`\lim`・`\max` などは後ろ（カーソルは下の添字へ）。補完をやめても、選んだものは残る（`pendingScope`・`consumeScope`） |

ほかの文字は、これまでどおり選んだものと置き換わる。コメントの行では、囲む記号だけが効く。
