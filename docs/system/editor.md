# エディタ（v2.8）

`narfi/src/web_ui.html`（1 ファイル）。ローカル版（`narfi web`）と Web 版で同じものを使う。

## 文書の持ち方
- 各行を構造化された木（`Seq` の中に文字・記号・分数・添字・絶対値・Σ などのノード）として持ち、その上でカーソルを動かす（Mathcha 風）。
- 保存するのは ASCII の文字列（`serializeDocToAscii`）。読み込みは `parseAsciiToItems`。往復で証明の意味が変わらないことをテストで確かめている（[testing.md](testing.md)）。
- 元に戻す・やり直すは木をそのまま複製して持つ。

## 表示の層（ファイルを変えない）
- 日本語シュガー（`JP`）：行を日本語の証明文の形で見せる。
- 添字・積・行列・Σ の見え方、宣言名の立体。
- ブロックの終わりの「∴ そのブロックで示したこと」（薄い表示）。

## 検査とのやりとり
- 編集が止まると `/api/check` に送る（Web 版は WebAssembly）。返ってくるのは、宣言ごとの結果・エラー（直し方 `fix`・候補 `alts`）・警告（書き換え先 `replace`）・各行の文脈と goal と次の一手（`steps[].hints`）・Prose・LaTeX・証明木。
- 直し方：行末の薄い文字（Tab で入る）、Goal タブの「次の一手」「根拠の候補」のボタン。原則 2（勝手に補わない）により、入れるのは必ず利用者の操作。

## 記法の補完（文脈の式）
検査器は各行について、goal と仮定に現れる式（`steps[].terms`。述語の定義を 3 段まで展開した形からも集める。数列の適用は `a_n`・`a_{n+1}` の形）と、数列の変数（`steps[].seqs`）を返す。エディタはそこから候補を出す。候補を出すだけで、Tab・Enter で選ぶまで入らない。

| 打つもの | 出る候補 |
|---|---|
| `\|`（項の始まり。直後が空白なら出さない：`Fix ε \| hε`） | 文脈の絶対値 `\|a_n − α\|` など。続けて打つと絞る。`\abs` の中でも出る |
| `(n \|->`（`(n ↦`） | 数列 `(n : ℕ ↦ a_n + b_n)` など（文脈の λ と、数列の変数から作る和・差・積・ずらし）。閉じ括弧ごと入る |
| `\sum` | 文脈の和と `sum(a, n)`（Σ_{k<n} a_k）。Σ の入力欄は `Σ_{k<n} 中身` で、走る添字は文脈で使っていない文字 |
| `Ctrl+Space`・`⌥Space` | 文脈の式すべて（打ちかけの語で絞る） |

Σ の入力欄は `sum((k : Nat |-> 中身), n)` と保存し、読み込むときも同じ形を Σ に戻す（`Σ_{k=0}^{m}` は `sum(…, m + 1)`）。見出しを書いている途中で検査が通らないときは、宣言の行の `a : ℕ → ℝ`・`n : ℕ` から候補を作る。

## 画面
- 上：File メニュー、開いたファイルのタブ、検査の結果、アカウント。下：サイドバー・日本語シュガー・テーマ・右側の表示切り替え。
- 左：ファイルの木（作成・名前の変更・削除・ドラッグで移動・右クリック）とライブラリ。
- 右：Goal（文脈・goal・次の一手・定理の一覧と依存する公理）・Prose・Source・LaTeX・AI・Learn。

## AI（任意）
- 設定は Preferences（接続先・モデル・API キー。形式は OpenAI と同じ chat/completions）。既定は OpenCode Go の `glm-5.3-flash`（`scripts/ai_bench.py` で、費用・速さ・正しさを比べて選んだ）。
- 右の AI タブ：「次の一手」（カーソルの位置に `sorry` を置いて検査し、そこの文脈と goal を渡す）・「sorry を埋める」・「エラーの説明」・質問。
- 「次の一手」「sorry を埋める」は、答えを検査器にかけ、通らなければエラーを返して直させる（最大 3 回・120 秒）。通った案だけに「入れる」ボタンを出す（原則 1・2）。途中までの案は、続きに `sorry` を置いた形で確かめる。入れたあとも「元に戻す」で戻せる。

## 数式の入力欄
エディタの入力欄（分数・添字・上付き・根号・絶対値・Σ・下に添字の付く演算子など）は、見た目を作るだけで意味を持たない。保存すると言語の文字列になり、意味は言語（組み込みの略記と notation）が決める（docs/language/syntax.md §3・§4.1）。
- 下に添字の付く演算子：`\lim`・`\limsup`・`\liminf`・`\max`・`\min`・`\sup`・`\inf`・`\argmax`・`\argmin`。打つと下に入力欄ができ、`\lim_{n -> infty}` と保存される。下が空なら `\max ` と保存される。
- 上付きの入力欄は `^` で作る（`\superscript` でも。`\sup` は上限の演算子）。
